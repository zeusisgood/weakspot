# Weak Spot Mining（弱点破壊 Mod）

Fortnite の資材集めにある「弱点（クリティカル）を叩くと速く壊せる」仕組みを Minecraft に持ち込む Mod です。

- 対応: **Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860**
- 最新版: **1.2.0**（[Releases](https://github.com/zeusisgood/weakspot/releases)、変更点は[更新履歴](#更新履歴)）

## 遊び方

### 採掘（左クリックの長押し）

1. いつもどおりブロックを長押しで壊し始めると、狙っている面に**弱点（円いマーク）**が出ます。
2. 照準を弱点に重ねると**ヒット**します。ヒット音が鳴り、少しの間だけ破壊が一気に進みます。
3. ヒットすると、弱点は離れた場所へ移動します。追いかけて当て続けると、通常の約2倍の速さで壊せます。
   - 移動するときは、マーカーが古い位置から新しい位置へ素早く（約0.08秒）動き、短い残像を残します（目で追いやすくするため）。見た目だけで、**当たり判定はヒットした瞬間から移動先にあります**。マーカーが動いている最中でも、移動先を狙えば当たります。成長・機械の弱点と、他のプレイヤーのマークも同じように動きます。設定 `weakSpotTrailEnabled` でオフにすると、その場で切り替わります。
4. 弱点に当てなくても、破壊は通常の速さで進みます。
5. 掘っている面の下の余白に、ブロックの残りの耐久が**緑のバー**で出ます。掘るにつれて右から縮み、弱点に当てると速く縮みます。床や天井を掘るときは、面の自分に一番近い辺に出ます。長押しをやめたとき、ブロックが壊れたとき、別のブロックを狙ったときは、すぐに消えます。設定 `blockHealthBarEnabled` でオフにできます。

6. 建築中など、弱点が邪魔なときは、**J キー**（操作設定で変更可）で自分の弱点を一時的にオフにできます。もう一度押すとオンに戻ります。切り替えると、画面の下にアクションバーで「弱点: オン／オフ」が出ます。オフの間は、採掘・成長・機械・動物・釣りの弱点と、耐久バー・成長バー・動物の足元のバーが出ず、通常の遊び方になります（他のプレイヤーのマークは見えます）。状態は保存され、オフのままワールドに入ると、アクションバーで知らせます。設定 `weakSpotsEnabled`。
   - 1.2.0 から、オン・オフの状態はサーバーにも伝わります。オフの間は、サーバーも、右クリックの抑止（機械の GUI、成長、動物の乗る・取引の画面など）、釣りの左クリックの抑止、ヒットの受け付けとブースト、自分のマークの転送を止めます。しゃがみ+素手の右クリックで、機械の GUI も開きます（1.1.6 までは、Mod 入りのサーバーでは開かない制限がありました）。

補足:

- ツールは問いません（素手でも有効）。
- 長押しをやめても、弱点は約2秒残ります。別の面を狙うと、その面に出し直します。
- 岩盤などの壊せないブロック、一瞬で壊れるブロック、クリエイティブモードは対象外です。
- 面が極端に小さいブロック（カーペットの側面など）には、弱点が出ません（面の短い辺が `minFaceSize` = 0.15 ブロック未満）。
- ボタンやハーフブロックなどの小さい面でも、弱点が当てやすく（半径に下限 `weakSpotMinRadius` = 0.08 を付けます）、ヒットしたら動くように、配置を面の大きさに合わせています（縁の余白と最小の移動距離を、面が小さいときは縮めます）。ふつうのブロックの動きは変わりません。
- 弱点そのものは各自のもので、当たり判定は自分の画面にしかありません。

### 作物・苗木などの成長（素手で右クリックを押しっぱなし）

- **素手**（メインハンドが空）で、育ちきっていない作物・苗木に向かって**右クリックを押しっぱなし**にすると、弱点が出ます（多くは上面）。
- **サトウキビ、サボテン、ネザーウォート**にも使えます。
  - サトウキビ・サボテンは、柱の高さが 3 未満で、一番上のすぐ上が空気のときに弱点が出ます（高さ 3 の柱には出ません）。弱点は側面に出て、柱のどの節に当てても、一番上の節が伸びます。土台（下の土と隣の水）がない高さ 1 のサトウキビには出ません。
  - ネザーウォートは、育ちきるまで弱点が出ます。育つかどうかが確率で決まるので、ほかより遅めです。
- 弱点に当てるたびに、そのブロックの成長が少し進みます。骨粉と違い、明るさや農地の水分などの成長の条件は守ったままです（条件を満たさない場所では、当てても育ちません）。
- 草ブロック、草、背の高い草花、キノコは、初期設定では対象外です（`growthExcludedBlocks`。サトウキビなども、ここに足せば対象外にできます）。

- 追加リスト（`growthExtraBlocks`）から、サトウキビなどを外したり、ほかの `IGrowable` を持たない植物を足したり（育つ条件をコードで決めてあるのは、サトウキビ・サボテン・ネザーウォートだけ。それ以外を足しても弱点は出ません）できます。除外リストは追加リストにも効きます。

### 機械の加速（しゃがんで、素手で右クリックを押しっぱなし）

- **しゃがんで、両手とも空**のまま、かまど・ホッパー・醸造台・モブスポナーや、他の Mod の機械（毎 tick 動くタイルエンティティを持つブロック）に向かって**右クリックを押しっぱなし**にすると、弱点が出ます。
- 弱点に当てるたびに、その機械が少しの間だけ速く動きます（Random Things の「Time in a Bottle」と同じ方式です）。電力や燃料の消費は、機械の作りどおりです（足りなければ速くなりません）。
- **素手でしゃがんで右クリックすると、機械の GUI は開きません。** しゃがまずに右クリックすれば、今までどおり開きます。何かを手に持っているときも、今までどおりの動作です。
- 宝箱、トラップチェスト、エンダーチェスト、エンチャントテーブル、ビーコン、シュルカーボックスは対象外です（しゃがんで素手で右クリックしても、GUI が普通に開きます）。

> **注意（機械の加速のリスク）**
> 機械の Mod の多くは、機械の処理が「1 tick に1回」だけ呼ばれる前提で作られています。余分に呼ぶと、不具合やクラッシュの原因になることがあります（Time in a Bottle でも、電力が足りない機械で例外が出た報告があります）。**ワールドのバックアップを取ってから使ってください。**
> 問題が出た機械は、設定の `excludedBlocks` に登録名（例: `modid:machine_name`）を足せば対象外にできます。
> 予約された tick で動くブロック（毎 tick 動くタイルエンティティを持たないもの）は、この方式では加速できません。

### 動物の弱点（素手で右クリックを押しっぱなし）

動物にも弱点が出ます。当てると、その動物のタイマーが進みます。**素手（両手が空）**で、動物に向かって**右クリックを押しっぱなし**にしてください（餌を持った右クリックは、今までどおり繁殖・餌やりです）。動物の当たり判定の箱の、照準が当たっている面に弱点が出て、動物が動いても一緒に動きます。

| 対象 | 弱点が出る条件 | 効果（目安のヒット数） |
|---|---|---|
| 子どもの成長 | 年齢を持つ動物（`EntityAnimal`。他の Mod の動物を含む）と村人の、子ども | 40ヒットで大人になる |
| 繁殖の待ち時間 | 同じ動物の、繁殖したあとの待ち時間中 | 10ヒットで待ち時間が終わる |
| 羊毛の再生 | 毛を刈られたバニラの羊 | 10ヒットで毛が生える（草は要りません） |
| 卵 | 大人のバニラのニワトリ（ニワトリ騎手を除く） | 15ヒットで次の卵を産む |
| 取引上限のリセット | ロック（×印）された取引がある、大人のバニラの村人 | 10ヒットでロックを解除する |

- 動いているタイマーがないとき（普通の大人の牛など）は、弱点は出ません。タイマーが複数あるときは、1ヒットで**すべて同時に**進みます。
- **しゃがみ+素手のときだけ**弱点が出る動物: 馬・ロバ・ラバ・ラマなど、飼いならしたオオカミ・ネコ・オウム、サドルを付けた豚、村人（子どもを含む）。素手の右クリックにバニラの別の動作（乗る、持ち物の画面、座る、取引の画面）があるためです。他の Mod の動物で同じように競合するものは、`animalSneakRequiredEntities` に足せます。
- 弱点が出る条件を満たしているときは、そのバニラの動作（乗る、持ち物の画面、座る、取引の画面）は起きません。条件を満たしていないとき、またはしゃがまずに右クリックしたときは、今までどおりの動作です（例: 大人の馬で競合するのは、繁殖したあとの約5分間の、しゃがみ+素手の右クリックだけです）。
- 弱点が出ている動物の**足元**に、進み具合の**黄色のバー**が出ます（子どもの成長 → 羊毛 → 取引上限 → 繁殖の待ち時間 → 卵の順で、先のタイマーを1本だけ出します）。他のプレイヤーには見えません。
- 村人の取引上限のリセットは、初期値では、**ロックの解除だけ**を行い、新しい取引の段階は解放しません。設定 `villagerResetUnlocksNewTier`（サーバーだけが使う）をオンにすると、バニラの補充と同じく、新しい取引の段階も解放します。
- 動物のタイマーは、サーバーだけが知っています。右クリックを押しっぱなしで動物に照準を合わせている間、クライアントは数 tick ごとにサーバーへ状態を問い合わせ、返事があってから弱点を出します。
- 動物の弱点も、近くの他のプレイヤーに見えます（足元のバーは見えません）。ヒット音とコンボには数えますが、節目と耐久回復には数えません。
- 目安のヒット数は、サーバーの設定で変えられます（`animalBabyHits` など。0 以下でその対象が無効になります）。

### 釣りの弱点（釣り竿を持って左クリック）

釣り竿の浮きが水に入って、魚が寄ってくるのを待っている間、浮きのまわり（半径1ブロック）の水面の上に弱点が出ます。**釣り竿を持って、弱点に照準が重なっているときに左クリック**で叩くと、魚が寄ってくるまでの待ち時間が短くなります（最長の待ち時間 600 tick を、6ヒットで 0 にする速さ。1ヒット = 5秒分）。

- 弱点は、浮きが遠くても近くても、**画面上で同じ大きさ**の円（半径 12 ピクセル）で出ます。浮きが画面の外や後ろにあるときは出ません。ヒットするたびに、浮きのまわりの別の点へ動きます。浮きの下に、魚が寄ってくるまでの進み具合のバーも出ます。
- 弱点に照準が重なっているときの左クリックは、弱点のヒットだけになり、通常の左クリック（照準の先のブロックを掘る、動物を攻撃する）は起きません。弱点から外れているときは、今までどおりです。
- 魚が寄ってきたあと（泡の筋が近づく段階）と、食いついたあとは、弱点は消えます。食いつきの判定と、巻き上げは、バニラのままです。**弱点を叩かなくても、今までどおり釣れます。**
- 釣りの弱点は、他のプレイヤーには見えません。ヒット音とコンボには数えますが、節目と耐久回復には数えません。
- 設定 `fishingWeakSpotEnabled` / `fishingHits` / `fishingMinHitIntervalTicks`（サーバーの値）。

### 耐久回復と節目

- ブロックを**壊したとき**に、そのブロックで採掘の弱点に当てた回数を数え、**5 回ごとに**、手に持っているツールの耐久が 1 回復します（耐久のないものや、減っていないものは回復しません）。
- 壊したブロックのヒットだけが対象です。壊さずにやめたブロックのヒットは数えません。5 回に満たない分は、次に壊すブロックへ持ち越します（ログアウトすると 0 に戻ります）。
- 1回の破壊で回復する耐久には上限があります（初期値 1。`maxRepairPerBreak`）。硬いブロックに何度も当てても、1回の破壊での回復はここまでです。
- 採掘の弱点に当てた回数が **100 / 777 / 1000 / 10000 回**に達すると、画面の中央とチャットで祝われ、花火が上がり、少しの経験値と耐久回復がもらえます。777 回は特に派手です。演出は本人の画面にだけ出ます。
- 成長・機械・動物・釣りのヒットは、耐久回復と節目には数えません。
- 節目の回数は、統計の「累計をリセット」では戻りません（同じ節目の報酬は、1つのワールドで1回だけです）。

### 他のプレイヤーの弱点マーク（マルチプレイ）

- 近くの他のプレイヤーが採掘で叩いている弱点が、**別の色（初期値は水色）**で見えます。見えるだけで、当たり判定はありません。
- 見える範囲はサーバーの設定 `markerShareRange`（初期値 16 ブロック）です。0 にすると見えなくなります。
- 近くのプレイヤーが弱点に当てると、そのマークも残像を引いて次の位置へ動きます（別の面やブロックに移ったときは、その場で切り替わります）。
- 表示のオンオフ・色・濃さは、各自の設定（`otherMarkerEnabled` / `otherMarkerColor` / `otherMarkerAlpha`）で変えられます。Forge の設定画面（統計画面の「設定画面を開く」からも開けます）で変えてください。
- 動物の弱点のマークも、同じ見た目・色・形で見えます（動物の足元のバーは見えません）。
- 成長・機械・釣りの弱点は、他のプレイヤーには見えません。

## ヒット音

- **自分のヒット音**: 初期値はノートブロックの「プリング」の音です。当て続けるとドレミの音階で1オクターブ上がり、上がりきると最初の音に戻って繰り返します。連続ヒットは別のブロックや別の種類（採掘・成長・機械・動物・釣り）に移っても続き、約2秒当てないと最初の音に戻ります。
- **他のプレイヤーのヒット音**（マルチプレイ）: 16ブロック以内にいる他のプレイヤーの採掘のヒット音も、叩かれたブロックの位置から聞こえます（離れるほど小さくなります）。初期値は木琴で、自分より小さめの音量です。音階は、そのプレイヤーの連続ヒットに合わせて上がります。
- 楽器と音量は、統計画面（K キー）の「**サウンド**」タブで、自分の音・他のプレイヤーの音のそれぞれについて変えられ、**試聴**もできます（試聴は距離なしで鳴ります）。Forge の設定画面の `myHitSound` / `myHitVolume` / `othersHitSound` / `othersHitVolume` と同じ値です。
- 音量を 0 にすると聞こえなくなります。バニラの「プレイヤー」の音量も掛かります（1.1.0 から、自分のヒット音にも掛かります）。

### コンボ（連続ヒットの表示）

- 連続ヒットが **2 以上**になると、照準の少し下に「**12 HIT**」のように数が出ます。ヒットのたびに数字が弾みます。
- 数え方はヒット音の音階と同じです。採掘・成長・機械・動物・釣りのヒットをすべて数え、別のブロックや別の種類に移っても続きます。**約2秒（40 tick）当てないと途切れ**、音階が最初の音に戻るのと同時にコンボも 0 に戻ります。死亡したとき、ディメンションを移動したとき、ワールドやサーバーから出たときも 0 に戻ります。
- 音階は1オクターブ（8 ヒット）で最初の音に戻りますが、コンボの数は戻らずに上がり続けます。
- 数字の色は、10 で黄、25 で橙、50 で赤、100 以上で虹色に変わります。10、25、50、100 に達した瞬間には、短い強調音（自分のヒット音の楽器で高い音。音量は自分のヒット音の音量）が鳴り、数字の周りが一瞬光ります。
- 数字の下のバーは、途切れるまでの残り時間です。ヒットすると満タンに戻り、残りが少なくなると赤く点滅します。
- 途切れると数字は薄くなって消えます。5 以上続いていたときは、「**MAX 23**」のように最後の数を約1秒残します。
- 自分のコンボだけが表示されます。画面の演出だけで、破壊の速さや報酬は変わりません。F1 で HUD を隠している間は表示しません。
- 表示のオンオフ・大きさ・位置・節目の演出のオンオフは、設定（`comboDisplayEnabled` / `comboScale` / `comboPosition` / `comboMilestoneEffects`）で変えられます。

## 統計

ゲーム中に **K キー**で統計画面を開けます（キーは「設定 → 操作設定 → 弱点破壊」で変更できます）。

統計は**サーバーが記録**します。サーバーが受け付けたヒットと、サーバーで壊れたブロックを数え、**ワールド（サーバー）ごと・プレイヤーごと**に、ワールドのセーブデータに保存します。死亡しても消えません。

| 項目 | 内容 |
|---|---|
| 弱点ヒット数（採掘） | 採掘の弱点に当てた回数 |
| 壊したブロック数 | 弱点が出るブロックを壊した数（一瞬で壊れるブロックは数えない） |
| 弱点を当てて壊したブロック数 | そのうち、1回以上当ててから壊した数 |
| 1ブロックあたりの平均ヒット数 | 弱点ヒット数 ÷ 壊したブロック数 |
| 1ブロックでの最多ヒット数 | 1つのブロックで当てた回数の最大 |
| 短縮できた時間（推定） | ヒットで先に進んだ破壊を、通常速度の時間に換算した合計 |
| 成長ヒット数 | 作物・苗木などの弱点に当てた回数 |
| 機械ヒット数 | 機械の弱点に当てた回数 |
| 動物ヒット数 | 動物の弱点に当てた回数 |
| 釣りヒット数 | 釣りの弱点に当てた回数 |
| 最大連続ヒット数 | 種類（採掘・成長・機械・動物・釣り）を問わない連続ヒットの最大。「弱点ヒット数」は採掘だけの数なので、数え方が違う。今回はそのワールドやサーバーに入ってから出るまでの最大、累計はそのワールド・サーバーでの最大 |

- **今回**: そのワールドやサーバーに入ってから出るまでの記録
- **累計**: そのワールド・サーバーでの合計。画面の「累計をリセット」を2回押すと消せます。全ワールド・全サーバーの合計は出せません。
- 自分の統計だけが表示されます（他のプレイヤーの統計は見られません）。
- 最大連続ヒット数はサーバーの tick で数えるので、画面のコンボとは、約2秒（40 tick）の境目のヒットのときだけ、ずれることがあります（目安です）。
- 1.0.x の統計（`.minecraft/weakspot/stats.json`）は使われず、引き継がれません。

## インストール

### どこに入れるか

| 遊び方 | Mod を入れる場所 |
|---|---|
| シングルプレイ | 自分のクライアントだけ |
| LAN（ワールドを LAN に公開） | ホストと、参加する全員のクライアント |
| マルチプレイ（専用サーバー） | **サーバーと、参加する全員のクライアント** |

- サーバーとクライアントには、**同じマイナーバージョン**（例: 1.2.x 同士）の jar を入れてください。パッチが違っていても（例: サーバー 1.2.0 とクライアント 1.2.1）接続できます。**1.2.x は、1.1.x とは接続できません。**詳しくは[バージョンの方針](#バージョンの方針)を参照してください。
- 次の場合は接続が拒否されます。
  - 片方にしか入っていない
  - マイナーバージョンが違う（例: 1.1.x と 1.2.x）
  - バニラ（Forge なし）のクライアントで接続した
- 弱点の表示とヒット判定は各クライアントが行い、破壊速度・成長・機械の加速・統計・報酬はサーバーが処理します。サーバーにも入れないと、壊したブロックが元に戻ります。

### 必要なもの

- Minecraft Java Edition **1.12.2**
- Minecraft Forge **1.12.2 - 14.23.5.2860**（[公式サイト](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.12.2.html)から入手）
- Java 8（Forge 1.12.2 の要件）
- この Mod の jar（`weakspot-<バージョン>.jar`）。[Releases](https://github.com/zeusisgood/weakspot/releases) からダウンロードしてください。自分でビルドする場合は[開発](#開発)の手順を参照してください。

### クライアント（シングルプレイ・マルチプレイ共通）

1. Forge のインストーラー（`forge-1.12.2-14.23.5.2860-installer.jar`）を実行し、「Install client」でインストールする。
2. Minecraft ランチャーで Forge 1.12.2 のプロファイルを一度起動して閉じる（`mods` フォルダが作られる）。
3. jar を `mods` フォルダに入れる。
   - Windows: `%APPDATA%\.minecraft\mods`
   - macOS: `~/Library/Application Support/minecraft/mods`
   - Linux: `~/.minecraft/mods`
4. Forge 1.12.2 のプロファイルで起動する。タイトル画面の「Mods」に「Weak Spot Mining」があれば導入できています。

### 専用サーバー

1. サーバー用のフォルダで、Forge のインストーラーをサーバーモードで実行する。

   ```sh
   java -jar forge-1.12.2-14.23.5.2860-installer.jar --installServer
   ```

2. 一度起動して `eula.txt` を作り、[Minecraft EULA](https://aka.ms/MinecraftEULA) に同意する場合は `eula=true` に書き換える。

   ```sh
   java -Xmx2G -jar forge-1.12.2-14.23.5.2860.jar nogui
   ```

3. jar をサーバーの `mods` フォルダに入れて、もう一度起動する。
4. 参加するプレイヤーにも、同じマイナーバージョンの jar を配ってクライアントに入れてもらう。

### 更新するとき

古い jar を `mods` から削除してから、新しい jar を入れてください。
- 同じマイナーの中の更新（例: 1.2.0 → 1.2.1）は、サーバーとクライアントを別々に更新してもかまいません。
- マイナーが変わる更新（例: 1.1.6 → 1.2.0）は、サーバーと全員のクライアントを同時に更新してください（マイナーが違うと接続できません）。

`config/weakspot.cfg` はそのまま引き継がれます。新しい設定項目は、次に起動したときに初期値で追加されます。統計はワールドのセーブデータにあるので、ワールドと一緒に引き継がれます。

## 設定

初回起動後に生成される `config/weakspot.cfg` で変更できます（サーバーでは、サーバーフォルダの `config/` に作られます）。ゲーム内では、タイトル画面の「Mods」→「Weak Spot Mining」→「設定」か、統計画面（K キー）の「設定画面を開く」で変えられます。

- **サーバー**の項目は、**サーバーの値が正**です。プレイヤーがログインしたときに、サーバーからクライアントへ送られ、接続している間はその値が使われます（切断すると自分の値に戻ります）。
  - 専用サーバーでは、サーバーの `config/weakspot.cfg` を書き換えて、サーバーを再起動してください。
  - シングルプレイと LAN のホストは、Mods メニューで変えられます（変えると、接続中の全員に送り直されます）。
  - 専用サーバーや他の人の LAN に接続している間は、自分の Mods メニューで変えたサーバーの項目は使われません（設定画面にもその旨が出ます）。
- **クライアント**の項目は、各自の設定として残ります。ヒット音の楽器・音量、他のプレイヤーのマークの表示・色・濃さ・形、コンボの表示、弱点の移動の演出、耐久バーと成長バーです。接続中も、自分の値が使われます。

### 作物の成長バー

成長の弱点を出している作物の足元に、成長の進み具合の**黄色のバー**が出ます（プレイヤーの方を向き、左から伸びます）。年齢（`age`）を持つ作物、苗木（`stage`）、サトウキビ・サボテン（弱点の効果がかかる一番上の節の年齢 ÷ 15）に対応します。設定 `growthBarEnabled`。

### 他のプレイヤーのマークの形

他のプレイヤーの弱点マークの形は、初期値で中抜きの**輪**です（自分のマークの塗りつぶした円と区別しやすくするため）。設定 `otherMarkerShape` で、円・ひし形・四角に変えられます。

### 管理コマンド（サーバー）

権限レベル 2（OP）以上が使えます。シングルプレイでは、チートがオンのときに使えます。対象はオンラインのプレイヤーだけです（オフラインのプレイヤーを指定すると案内が出ます）。プレイヤー名はタブキーで補完できます。

| コマンド | 内容 |
|---|---|
| `/weakspot` | 使い方を表示する |
| `/weakspot stats <プレイヤー>` | そのプレイヤーの統計（今回と累計）をチャットに表示する |
| `/weakspot reset <プレイヤー>` | そのプレイヤーの統計の累計を消す（統計画面の「累計をリセット」と同じ） |

### ブーストの目安

1回のヒットで、通常の `(倍率 − 1) × 継続時間` tick 分だけ破壊が進みます（初期値では 12 tick = 約0.6秒分）。約0.6秒ごとにヒットすると通常の約2倍の速さになり、`minHitIntervalTicks` の制限により最大で約3倍になります。

## 開発

JDK 8 が必要です。リポジトリの devcontainer を使うと、JDK 8 と Claude Code が入った環境で開発できます。

```sh
./gradlew build        # ビルドとテスト。成果物は build/libs/
./gradlew test         # 単体テストのみ
./gradlew runServer    # 開発用の専用サーバーを起動（run/ で起動。初回は run/eula.txt の同意が必要）
```

コンテナ内ではゲーム画面を出せないため、クライアント側の動作は、ビルドした jar をホスト側の Minecraft の `mods` に入れて確認します。

ソースは `com.example.weakspot` 以下にあります。

## バージョンの方針

- **パッチ**（1.2.0 → 1.2.1）: 機能の追加や、不具合の修正です。通信内容や保存データの形式は変えないので、同じ 1.2.x の間は、サーバーとクライアントのパッチ版が違っていても接続できます。
- **マイナー**（1.2.x → 1.3.0）: 互換性が壊れる変更です（通信内容の変更、古い版では読めない保存データの変更、設定キーの削除や意味の変更）。マイナーが違うと接続できないので、サーバーと全員のクライアントを、同じマイナーに更新してください。
- 迷ったときは、マイナーを上げます。

- 機械に、しゃがんで右クリックしっぱなしで弱点が出て、当てると加速されるようにした（機械 MOD によっては不具合の原因になることがある。ワールドのバックアップを取ってから使うこと）
