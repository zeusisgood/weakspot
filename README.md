# Weak Spot Mining（弱点破壊 Mod）

[![最新版](https://img.shields.io/github/v/release/zeusisgood/weakspot?label=%E6%9C%80%E6%96%B0%E7%89%88)](https://github.com/zeusisgood/weakspot/releases/latest)

Fortnite の資材集めにある「弱点（クリティカル）を叩くと速く壊せる」仕組みを、Minecraft に持ち込む Mod です。掘る・育てる・走る・弓を引く……いろいろな場面に光る円（弱点）が出て、当てると速くなります。

## ⬇ ダウンロード

- **[weakspot-1.8.6.jar をダウンロード](https://github.com/zeusisgood/weakspot/releases/download/v1.8.6/weakspot-1.8.6.jar)**（最新版 1.8.6。クリックするとすぐ落とせます）
- [ほかの版・リリースノート（Releases のページ）](https://github.com/zeusisgood/weakspot/releases/latest)

対応: **Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860**

## はじめかた（3 ステップ）

1. [Minecraft Forge 1.12.2 - 14.23.5.2860](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.12.2.html) を入れる
2. ダウンロードした jar を、`.minecraft` の中の **`mods` フォルダ**に入れる（なければ作る）
3. Forge のプロファイルで起動する。初めてワールドに入ると、遊び方の**ガイドの本**がもらえる

- **マルチプレイ**では、サーバーと、入る人全員に同じ版の jar が要ります。
- 詳しいインストール（専用サーバー・更新のしかた）は [doc/install.md](doc/install.md)。

## 操作

| キー | すること |
|---|---|
| **K** | 弱点破壊のメニュー（統計・ヒット音・弱点マーカー（種類ごとのオン・オフと色・形）・設定・ガイド） |
| **HOME** | 弱点をすべてオン・オフ（建築中など、邪魔なときに） |

キーは「設定 → 操作設定 → 弱点破壊」で変えられます。

## 弱点の種類

| 種類 | どうする | 当てると |
|---|---|---|
| [採掘](doc/play.md#採掘左クリックの長押し) | 左クリックの長押しでブロックを掘る | 速く掘れる。壊すと道具の耐久が少し戻る |
| [作物・苗木](doc/play.md#作物苗木などの成長素手で右クリックを押しっぱなし) | 素手で、育ちきっていない作物・苗木に右クリックを押しっぱなし | 少し育つ |
| [収穫](doc/play.md#収穫の弱点実った作物を素手で右クリックを押しっぱなし) | 素手で、実った作物に右クリックを押しっぱなし | 収穫して植え直す |
| [機械の加速](doc/play.md#機械の加速しゃがんで素手で右クリックを押しっぱなし) | しゃがんで素手で、かまどなどの機械に右クリックを押しっぱなし | 機械が速く動く |
| [動物](doc/play.md#動物の弱点素手で右クリックを押しっぱなし) | 素手で動物に右クリックを押しっぱなし（馬・村人などはしゃがんで） | 子どもの成長・繁殖・羊毛・卵・村人の取引の回復が早まる |
| [釣り](doc/play.md#釣りの弱点釣り竿を持って左クリック) | 浮きのまわりの弱点を、釣り竿を持って左クリック | 魚が早く寄ってくる |
| [弓](doc/play.md#弓の弱点弓を引いている間照準を合わせる) | 弓を引いている間、照準を弱点に合わせる | 早く引ける。引き切ったあとは矢が強くなる |
| [近接](doc/play.md#近接の弱点剣か斧を持って敵の近くで照準を合わせて溜める) | 剣か斧を持って敵の近くで、照準を合わせる | 溜まって、次の攻撃が強いクリティカルに |
| [投げる物](doc/play.md#投げる物の弱点持っている間照準を合わせる) | エンダーパール・雪玉などを持って、照準を合わせる | 次に投げた物が速く遠くへ飛ぶ |
| [食事・飲み物](doc/play.md#食事飲み物の弱点食べている間照準を合わせる) | 食べる・飲む間、照準を合わせる | 早く食べ終わる |
| [乗り物](doc/play.md#乗り物の弱点乗って走りながら照準を合わせる) | 馬・豚・トロッコ・ボートで走りながら、照準を合わせる | 速く走る |
| [はしご](doc/play.md#はしごの弱点登り降りしながら照準を合わせる) | はしご・ツタを登り降りしながら、照準を合わせる | 速く登り降りできる |
| [走り](doc/play.md#走りの弱点走りながら照準を合わせる) | 走りながら、照準を合わせる | 速く走れる |
| [エリトラ](doc/play.md#エリトラの弱点飛びながら照準を合わせる) | エリトラで飛びながら、照準を合わせる | 見ている向きへ一気に飛び出す |
| [ネザーゲート](doc/play.md#ネザーゲートの弱点ゲートの中で照準を合わせる) | ゲートの中で、照準を合わせる | 早く移動できる |
| [睡眠](doc/play.md#寝ている間の弱点夜にベッドで寝ている間クリックで当てる) | 夜にベッドで寝ている間、画面のマーカーをクリック | 朝が早く来る |
| [エンチャント](doc/play.md#エンチャントの弱点エンチャント台の画面でクリックで当てる) | エンチャント台の画面のマーカーをクリック | 3 つの候補を引き直す（何も減らない） |

どれも、当てると**コンボ**が続き、ヒット音が上がっていきます。種類ごとの詳しい説明は [doc/play.md](doc/play.md)。

## 最近の更新

### 1.8.6

- **クリエイティブでも、すべての弱点が出る**ようにした（採掘は、ブロックが一瞬で壊れるので出ない）。観戦モードでは出ない。サーバーが 1.8.5 以前のときは、今までどおり出ない
- 内部を整理した（ヒットの受け付けの共通化、ヒットの振り分けの表、統計・送る設定の持ち方、照準のまわりの弱点の共通の土台、コンボの掛け数）。遊び方は変わらない
- 通信内容・保存データ・設定は変わっていない（統計と設定の送る中身が 1 バイトも変わらないことを、テストで確かめた）。1.8.x 同士は、そのまま接続できる

### 1.8.5

- ガイドの本を整理した: 表紙・**クリックで飛べる目次**・6 つの章に並べ替え、各ページを「■ 出るとき」「■ 当てると」「■ ヒント」の見出しで分けた。各ページの下の「↩ 目次」で戻れる。「照準のまわりの弱点」「弱点マーカー」「困ったとき」のページを足した
- 前の版でもらった本は、ログインしたとき・開こうとしたときに、新しい本に差し替わる
- 通信内容・設定は変わっていない。1.8.x 同士は、そのまま接続できる（1.8.4 以前のクライアントでは、1.8.5 のサーバーでもらった本の文章がキーのまま出る）

### 1.8.4

- 大人の村人に、しゃがんで素手で右クリックを押しっぱなしにすると、**繁殖できない理由**（村・ドア・待ち時間・食べ物・相手）をアクションバーに出すようにした
- 動物の表の「繁殖の待ち時間」に、村人も対象だと書いた
- 通信内容・設定は変わっていない（文章はサーバーが作って送る）。1.8.x 同士は、そのまま接続できる

全部の更新履歴は [CHANGELOG.md](CHANGELOG.md)。
