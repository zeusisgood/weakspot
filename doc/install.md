# 導入

[← README に戻る](../README.md)

必要環境は次のどちらかです。Mod の jar は [CurseForge](https://www.curseforge.com/minecraft/mc-mods/weakspot) から、Minecraft の版に合うもの（名前の先頭の版）を入手し、`mods` フォルダに入れてください。

| Minecraft | ローダー | jar |
|---|---|---|
| Java Edition **1.12.2** | Minecraft Forge（1.12.2 用。開発・動作確認は 14.23.5.2860。古い Forge では一部の機能が動かない可能性あり） | `weakspot-1.12.2-forge-<版>.jar` |
| Java Edition **1.21.1** | NeoForge（1.21.1 用の 21.1.x。開発・動作確認は 21.1.264。[NeoForge](https://neoforged.net/) のインストーラーで入れる。Forge 用の Mod とは別） | `weakspot-1.21.1-neoforge-<版>.jar` |

どちらの版も遊び方・設定の項目は同じです（1.21.1 で増えた乗り物などは 1.21.1 版でだけ対象。[遊び方](play.md)）。

## 導入先

| プレイ形態 | 導入先 |
|---|---|
| シングルプレイ | 自分のクライアントのみ |
| LAN（ワールドを LAN に公開） | ホストと、参加者全員のクライアント |
| マルチプレイ（専用サーバー） | **サーバーと、参加者全員のクライアント** |

- 弱点の表示とヒット判定は各クライアントが、破壊速度・成長・機械の加速・統計・報酬はサーバーが処理します。サーバーに導入しないと、壊したブロックが元に戻ります。
- サーバーとクライアントは**同じバージョン**を推奨します。パッチ違い（例: 1.8.5 と 1.8.6）でも接続できますが、新しい側だけの機能は動作しない場合があります。バージョンが違うと、ログイン時に本人と OP のチャット、サーバーのログで通知されます。
- マルチプレイでエリトラの弱点を続けて当てると、速すぎるとしてサーバーに元の位置へ引き戻されることがあります（サーバーのログに `moved too quickly!`。シングルプレイでは起きません）。サーバーのコンソールか OP で `/gamerule disableElytraMovementCheck true` を実行すると、エリトラで飛行中だけこの確認が止まります（ワールドに保存）。`server.properties` の `allow-flight=true` では止まりません。
- 次の場合は接続が拒否されます: 片方にしか導入していない／マイナーバージョンが違う（例: 1.11.x と 1.12.x）／バニラ（Forge・NeoForge なし）のクライアント。Minecraft の版が違う（1.12.2 と 1.21.1）と、そもそも接続できません。詳しくは[バージョンの方針](development.md#バージョンの方針)。

## 更新時

古い jar を `mods` から削除してから、新しい jar を入れてください。

- 同じマイナー内の更新（例: 1.8.5 → 1.8.6）は、サーバーとクライアントを別々に更新しても構いません。
- マイナーが変わる更新（例: 1.8.9 → 1.9.0）は、サーバーと全員のクライアントを同時に更新してください。
- 新しいバージョンが公開されると、ゲーム内のチャットでも通知されます（GitHub からバージョンの情報だけを取得。停止するには `checkForUpdates=false`）。
- 設定ファイル（1.12.2 版は `config/weakspot.cfg`、1.21.1 版は `config/weakspot-server.toml` と `config/weakspot-client.toml`）はそのまま引き継がれ、新しい設定項目は次回起動時に初期値で追加されます。統計はワールドのセーブデータに保存されるため、ワールドと一緒に引き継がれます。1.12.2 のワールドを 1.21.1 で開いても、統計・記録は引き継がれません（0 から始まります）。
