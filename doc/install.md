# インストール

[← README に戻る](../README.md)

## どこに入れるか

| 遊び方 | Mod を入れる場所 |
|---|---|
| シングルプレイ | 自分のクライアントだけ |
| LAN（ワールドを LAN に公開） | ホストと、参加する全員のクライアント |
| マルチプレイ（専用サーバー） | **サーバーと、参加する全員のクライアント** |

- サーバーとクライアントには、**同じバージョン**の jar を入れてください。パッチだけが違う場合（例: サーバー 1.5.0 とクライアント 1.5.1）も接続はできますが、新しい側にしかない機能が正しく動かないことがあります（例: 1.4.3 のサーバーに 1.4.4 のクライアントでつなぐと、ディスペンサーの弱点が出るのに GUI が開く）。1.5.1 からは、版が違うと、ログインしたときに本人・OP 権限を持つプレイヤーのチャットと、サーバーのログで知らせます。マイナーが違う場合（例: 1.6.x と 1.5.x）は接続できません。1.6.0 からは、クライアントがサーバーの版を知っていて、今後のパッチで足す機能は、古いサーバーにつないだときは出さないようにします。詳しくは[バージョンの方針](development.md#バージョンの方針)を参照してください。
- 次の場合は接続が拒否されます。
  - 片方にしか入っていない
  - マイナーバージョンが違う（例: 1.5.x と 1.6.x）
  - バニラ（Forge なし）のクライアントで接続した
- 弱点の表示とヒット判定は各クライアントが行い、破壊速度・成長・機械の加速・統計・報酬はサーバーが処理します。サーバーにも入れないと、壊したブロックが元に戻ります。

## 必要なもの

- Minecraft Java Edition **1.12.2**
- Minecraft Forge **1.12.2 - 14.23.5.2860**（[公式サイト](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.12.2.html)から入手）
- Java 8（Forge 1.12.2 の要件）
- この Mod の jar（`weakspot-<バージョン>.jar`）。[Releases](https://github.com/zeusisgood/weakspot/releases) からダウンロードしてください。自分でビルドする場合は[開発](development.md)の手順を参照してください。

## クライアント（シングルプレイ・マルチプレイ共通）

1. Forge のインストーラー（`forge-1.12.2-14.23.5.2860-installer.jar`）を実行し、「Install client」でインストールする。
2. Minecraft ランチャーで Forge 1.12.2 のプロファイルを一度起動して閉じる（`mods` フォルダが作られる）。
3. jar を `mods` フォルダに入れる。
   - Windows: `%APPDATA%\.minecraft\mods`
   - macOS: `~/Library/Application Support/minecraft/mods`
   - Linux: `~/.minecraft/mods`
4. Forge 1.12.2 のプロファイルで起動する。タイトル画面の「Mods」に「Weak Spot Mining」があれば導入できています。

## 専用サーバー

1. サーバー用のフォルダで、Forge のインストーラーをサーバーモードで実行する。

   ```sh
   java -jar forge-1.12.2-14.23.5.2860-installer.jar --installServer
   ```

2. 一度起動して `eula.txt` を作り、[Minecraft EULA](https://aka.ms/MinecraftEULA) に同意する場合は `eula=true` に書き換える。

   ```sh
   java -Xmx2G -jar forge-1.12.2-14.23.5.2860.jar nogui
   ```

3. jar をサーバーの `mods` フォルダに入れて、もう一度起動する。
4. 参加するプレイヤーにも、同じマイナーバージョンの jar を配ってクライアントに入れてもらう。

## 更新するとき

古い jar を `mods` から削除してから、新しい jar を入れてください。
- 同じマイナーの中の更新（例: 1.4.0 → 1.4.1）は、サーバーとクライアントを別々に更新してもかまいません。
- マイナーが変わる更新（例: 1.3.7 → 1.4.0）は、サーバーと全員のクライアントを同時に更新してください（マイナーが違うと接続できません）。

`config/weakspot.cfg` はそのまま引き継がれます。新しい設定項目は、次に起動したときに初期値で追加されます。統計はワールドのセーブデータにあるので、ワールドと一緒に引き継がれます。
