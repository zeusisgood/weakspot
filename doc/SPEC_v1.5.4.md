# 弱点破壊 Mod 追加仕様書（v1.5.4）

`SPEC_v1.5.3.md`（Mod 1.5.3）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/SPEC_v1.5.4.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.5.3 がリリース済み。1.5.3 の内容を土台にする
- 内容: 弓の弱点を、照準からもっと離れた所に出す（今の 3〜8 度は近すぎて、照準をほとんど動かさずに当たる、というユーザーの指摘）
- この仕様書の内容は、Mod のバージョン **1.5.4** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.5.3 → **1.5.4**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.5,1.6)`）は、変えない
- **パッチなので、互換性を破る変更を入れない**。弓の弱点の向きはクライアントだけが決めている（サーバーは向きを確かめない）ので、通信・設定・保存データは変わらない。古いサーバーにつないでも同じように動く

## 1. 弱点の向き（`common/BowMath`、クライアント）

- 視線からずらす角度: **3〜8 度 → 10〜20 度**（`MIN_OFFSET_DEGREES` / `MAX_OFFSET_DEGREES`）
- ヒットのあと、前の向きから最低でも離れる角度: **4 度 → 8 度**（`MIN_MOVE_DEGREES`）
- **画面からはみ出さないように**、今の縦の視野角で上限を抑える: 上限 = min(20 度, 縦の視野角の半分 × 0.7)、下限 = min(10 度, 上限の半分)。弓を引くと視野が狭くなる、視野角の設定を小さくしている、などのとき（`BowMath.offsetRange(縦の視野角)`。視野角はフレームごとに `ScreenProjection.fovDegrees` で求めている）
  - 例: 視野角 70 度（初期値）で弓を引き切ると、縦の視野角はおよそ 60 度 → 上限 20 度のまま。視野角 30 度なら、上限 10.5 度・下限 5.25 度
- 範囲の計算は単体テストを書く

## 2. README とガイドの本

- README の弓の節の「視線から 3〜8 度ずれた向き」を「10〜20 度ずれた向き（画面が狭いときは、はみ出さないように近づける）」に
- ガイドの本の 8 ページ目（弓）の「照準の近くに弱点が出ます」を「照準から少し離れた所に弱点が出ます。照準を動かして合わせると」の旨に（日本語で 150 文字くらいまで）
- 「最新版」の行を 1.5.4 にし、「更新履歴」に 1.5.4 を追加する（通信内容は変わっていない。クライアントだけの変更なので、サーバーは 1.5.x のどれでもよい）
- 「開発」の節の仕様書へのリンクに `doc/SPEC_v1.5.4.md` を足す

## 3. `CLAUDE.md` に書くこと

- 「仕様の正本」の一覧に `doc/SPEC_v1.5.4.md` を足す。現行のバージョンを 1.5.4 に
- 弓の弱点の説明の「3〜8 度」を「10〜20 度（視野角で上限を抑える）」に

## 4. ユーザーに確認してもらうこと

- 弓を引くと、弱点が照準からはっきり離れた所に出ること。照準を動かさないと当たらないこと
- 弓を引き切って視野が狭くなっても、弱点が画面からはみ出さないこと
- 遠すぎて当てにくくないか（遠すぎれば、角度を調整する）
