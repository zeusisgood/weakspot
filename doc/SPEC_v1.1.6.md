# 弱点破壊 Mod 追加仕様書（v1.1.6）

`SPEC_v1.1.md`（Mod 1.1.0）から `SPEC_v1.1.5.md`（Mod 1.1.5）までに対する**パッチ**の仕様。ここに書かれていないことは、それらと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/SPEC_v1.1.6.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.1.5 がリリース済み。1.1.5 の内容を土台にする
- 内容: 次の4つ
  1. 作物の成長バー（クライアント）
  2. 他のプレイヤーの弱点マークの形（クライアント）
  3. 弱点の一時オフのキー（クライアント）
  4. 管理コマンド（サーバー）
- この仕様書の内容は、Mod のバージョン **1.1.6** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.1.5 → **1.1.6**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.1,1.2)`）は、変えない。1.1.x 同士は、互いに接続できる
- **パッチなので、互換性を破る変更を入れない**（`SPEC_v1.1.md` §0 のバージョンの方針）
  - パケットの追加・削除・中身の変更をしない。`SyncedSettings` に、項目を足さない
  - サーバーが保存するデータの形式を変えない
  - 設定キーの削除や、意味の変更をしない
- 1〜3 は**クライアントだけ**、4 は**サーバーだけ**の変更

## 1. 作物の成長バー（クライアント）

成長の弱点を出している作物の足元に、成長の進み具合のバーを出す。1.2.0 で、動物の足元のバー（`SPEC_v1.2.md`）に、同じ描き方を流用する前提で作る。

### 1.1 表示する値
作物の成長段階は、ブロックの状態としてクライアントも知っているので、クライアントだけで計算できる。

| ブロック | 値 |
|---|---|
| 年齢（`age`）の数値プロパティを持つブロック（小麦、ニンジン、ジャガイモ、ビートルート、スイカ・カボチャのくき、ココア、ネザーウォート、MOD の作物の多く） | 年齢 ÷ 最大の年齢 |
| 苗木（`stage`） | 段階 ÷ 最大の段階（粗い表示になる） |
| サトウキビ、サボテン | 弱点の効果がかかる**柱の一番上の節**の年齢 ÷ 15（次の節が伸びるまでの進み具合） |
| 上のどれにも当たらない | バーを出さない |

- 「年齢の数値プロパティ」は、名前が `age` の整数のプロパティで判定する（MOD の作物にも効くように）。判定の方法は実装時に確認する（§5）
- 値は 0.0〜1.0 に収める

### 1.2 表示の場所と形
- 作物のブロックの**足元**（ブロックの下端から少し上）に、**プレイヤーの方を向いた**横長のバーを浮かべる（ワールドの中に描く）
- 太さ **0.06 ブロック**、長さ **0.6 ブロック**。ブロックの中央にそろえる
- 作物の見た目（十字の模型など）に隠されないように描く（深度テストを切る、またはプレイヤー側へ少し寄せる。方法は実装で決めてよい）
- この描き方は、1.2.0 で、動物の足元のバーに流用する。汎用の部品として作る（位置と向きと値を渡せば描ける形）

### 1.3 色

| 部分 | 色 |
|---|---|
| 進み具合（たまっていく） | 黄 `#FFD23F` |
| 背景（バーの全体） | 黒 `#1E1E1E`（半透明。透明度 50% 程度） |

- 進み具合は、プレイヤーから見て**左から**伸びる

### 1.4 表示する条件
- その作物に、成長の弱点が出ている間（素手で右クリックを押しっぱなしにしている間）だけ
- 弱点が消えたら、すぐに消す
- 弱点の一時オフ（§3）の間は、出さない

### 1.5 設定（クライアント）

| キー | 初期値 | 説明 |
|---|---|---|
| `growthBarEnabled` | `true` | 作物の成長バーの表示のオンオフ |

## 2. 他のプレイヤーの弱点マークの形（クライアント）

`SPEC_v1.1.md` §8.5 で「後のバージョン」にしていた、形の変更。色だけでは見分けにくい人向け。

### 2.1 形
| 値 | 形 |
|---|---|
| `CIRCLE` | 塗りつぶした円（1.1.5 までと同じ） |
| `RING` | 中抜きの輪 |
| `DIAMOND` | ひし形 |
| `SQUARE` | 四角 |

- 大きさは、今までどおり（弱点の半径に合わせる）
- 色と透明度は、今までどおり、`otherMarkerColor` と `otherMarkerAlpha` に従う
- 1.1.4 の移動の残像も、同じ形で描く
- 自分のマークは、今までどおり、塗りつぶした円のまま
- 他のプレイヤーのマークには当たり判定がないので、形を変えても、遊び方は変わらない

### 2.2 設定（クライアント）

| キー | 初期値 | 説明 |
|---|---|---|
| `otherMarkerShape` | `RING` | 他のプレイヤーの弱点マークの形 |

- 初期値は、自分のマーク（塗りつぶした円）と区別しやすい `RING` にする

## 3. 弱点の一時オフのキー（クライアント）

建築中など、弱点が邪魔なときに、弱点を止めて、普通の遊び方に戻せるようにする。

### 3.1 操作
- キーを押すたびに、弱点の**オン**と**オフ**が切り替わる
- 初期のキーは **J**（Minecraft の「操作設定」で変えられる。キーの名前と分類は、統計画面のキーと同じ分類に置く）
- 切り替えたときに、アクションバー（画面の下の中央）に「弱点: オン」「弱点: オフ」を短く出し、小さな音を鳴らす

### 3.2 オフの間の動き
- 自分の弱点を、**すべて**出さない（採掘・成長・機械）
- ヒットの通知を送らない。自分の弱点マークの状態も送らない（オフにした瞬間に、出ていた弱点の「消えた」を送る）
- 採掘は、通常の速さになる
- 成長・機械の右クリックは、Minecraft の通常の動作になる（機械の GUI の抑止もしない）
- 耐久バー（1.1.5）と、作物の成長バー（§1）も出さない
- 他のプレイヤーの弱点マークは、今までどおり見える（自分の弱点だけを止める）
- 統計画面（K キー）は、今までどおり開ける
- サーバーは変えない（ヒットが来ないだけ）

### 3.3 状態の保存
- オン・オフの状態は、クライアントの設定に保存して、次に起動したときも引き継ぐ（キー `weakSpotsEnabled`、初期値 `true`）
- オフのままワールドやサーバーに入ったときは、入ったときに、アクションバーに「弱点: オフ（J で切り替え）」を出して、オフになっていることに気づけるようにする（キーの名前は、実際に割り当てられたキーを出す）

### 3.4 設定（クライアント）

| キー | 初期値 | 説明 |
|---|---|---|
| `weakSpotsEnabled` | `true` | 自分の弱点のオン・オフ（§3 のキーで切り替わる） |

## 4. 管理コマンド（サーバー）

サーバーの管理者が、プレイヤーの統計を見たり、消したりできるようにする。

### 4.1 コマンド

| コマンド | 内容 |
|---|---|
| `/weakspot` | 使い方を表示する |
| `/weakspot stats <プレイヤー>` | そのプレイヤーの統計（統計画面と同じ項目。今回と累計）を、チャットに表示する |
| `/weakspot reset <プレイヤー>` | そのプレイヤーの統計の累計を消す。統計画面の「累計をリセット」と同じ動き（消す範囲も同じ） |

### 4.2 ルール
- 権限レベル **2**（OP）以上が使える。シングルプレイでは、チートがオンのときに使える
- 対象は、**オンラインのプレイヤーだけ**。オフラインのプレイヤーを指定したときは、「オンラインのプレイヤーだけ指定できます」と表示する（オフラインのプレイヤーのデータの読み書きは、後のバージョンで考える）
- プレイヤー名は、タブキーで補完できる
- `reset` で統計を消したとき、そのプレイヤーが統計画面を開いていれば、次に開き直したときに反映されればよい（通信は増やさない）
- 表示の文字列は、翻訳キー（`TextComponentTranslation`）で出し、`en_us.lang` と `ja_jp.lang` の両方に足す（クライアントにも Mod が入っている前提なので、翻訳される）
- サーバーの起動時（`FMLServerStartingEvent`）に登録する。クライアントの変更はない

## 5. 実装時に確認すること

- 作物の年齢のプロパティの取り方（名前が `age` の整数のプロパティを、ブロックの状態から探す方法）。苗木の `stage`。サトウキビ・サボテンの柱の一番上の節の探し方（1.1.2 の `GrowthRoom` などを流用できるか）
- 作物の成長バーが、作物の見た目に隠れない描き方
- 1.1.5 の耐久バーの描き方と、共通の部品にできるところ
- 一時オフのときに、止める必要がある処理の一覧（ヒットの送信、マークの送信、弱点の表示、機械の GUI の抑止、右クリックの抑止、耐久バー、成長バー）。止め忘れがないこと
- キー J が、Minecraft 1.12.2 の標準の操作と重ならないこと
- 統計のデータ（`PlayerPersisted` の `weakspot` など）の読み方と、「累計をリセット」の処理を、コマンドから呼べるか

## 6. 単体テスト

`common/` に置く純粋な計算に、テストを書く。
- 成長の進み具合: 年齢 0 → 0.0、最大 → 1.0、途中の値。範囲外の値を、0.0〜1.0 に収めること
- サトウキビ・サボテンの進み具合: 年齢 0〜15 から、0.0〜1.0 になること
- マークの形の選択: 設定の値から、形が選ばれること。知らない値のときは `RING` に戻ること
- 一時オフの状態: 切り替えのたびに、オンとオフが入れ替わること

## 9. ユーザーに確認してもらうこと（クライアントの見た目は、Claude Code が確認できない）

ビルドした jar を、ホストの Minecraft で試す。

- 成長バー: 小麦に、素手で右クリックを押しっぱなしにすると、足元に黄色のバーが出て、弱点に当てて育つと伸びること。作物に隠れないこと。右クリックをやめると消えること
- 成長バー: サトウキビ（柱の一番上の節の進み具合）、苗木、ネザーウォート、ココアでも出ること
- マークの形: 他のプレイヤーのマークが、初期値で中抜きの輪になること。設定で、ひし形・四角・円に変わること。移動の残像も同じ形になること
- 一時オフ: J キーで、アクションバーに「弱点: オフ」が出て、採掘・成長・機械のどれでも弱点が出なくなること。採掘が通常の速さになること。機械のしゃがみ右クリックで GUI が開くこと。耐久バーと成長バーが出ないこと。もう一度押すと戻ること
- 一時オフ: オフのまま、ゲームを再起動してワールドに入ると、オフのままで、アクションバーで知らせてくれること
- 管理コマンド: OP のプレイヤーが、`/weakspot stats <名前>` で統計を見られること。`/weakspot reset <名前>` で累計が消えること。OP でないプレイヤーは使えないこと。オフラインのプレイヤーを指定すると、案内が出ること
- 1.1.5 のサーバー（またはクライアント）と、1.1.6 のクライアント（またはサーバー）で、接続できること
