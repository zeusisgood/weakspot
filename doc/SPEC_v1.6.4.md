# 弱点破壊 Mod 追加仕様書（v1.6.4）

`SPEC_v1.6.3.md`（Mod 1.6.3）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/SPEC_v1.6.4.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.6.3 がリリース済み。1.6.3 の内容を土台にする
- 内容: 乗り物の加速の残り時間のゲージ（1.6.0、水色）が、照準の下のコンボの表示（「5 HIT」）と重なっていた（ユーザーの報告。騎射の画面）。ゲージを**照準の上**に移す
- この仕様書の内容は、Mod のバージョン **1.6.4** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.6.3 → **1.6.4**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.6,1.7)`）は、変えない
- **パッチなので、互換性を破る変更を入れない**。クライアントの描き方だけの変更

## 1. ゲージの位置（`client/VehicleSpot`）

- 今: 照準の中心から**下に 22** GUI ピクセル。コンボの表示（初期値の位置 `BELOW_CROSSHAIR` では、照準の下 16 ピクセルから）と重なる
- 変更後: 照準の中心から**上に 12** GUI ピクセル（弓の引きゲージ（下に 12）と、照準をはさんで上下対称）。大きさ（幅 40、太さ 3）と色（水色 `#55CCFF`）は変えない

## 2. README

- 乗り物の弱点の節の「照準の下に残り時間のゲージ」を「照準の上に」に
- 設定表の `vehicleBoostBarEnabled` の説明の「照準の下」を「照準の上」に
- 「最新版」の行を 1.6.4 にし、「更新履歴」に 1.6.4 を追加する（クライアントだけの修正）
- 「開発」の節の仕様書へのリンクに `doc/SPEC_v1.6.4.md` を足す

## 3. `CLAUDE.md` に書くこと

- 「仕様の正本」の一覧に `doc/SPEC_v1.6.4.md` を足す。現行のバージョンを 1.6.4 に
- 乗り物の弱点の説明の「照準の下の残り時間のゲージ」を「照準の上の（1.6.4）」に

## 4. ユーザーに確認してもらうこと

- 馬に乗って弓を撃ちながら加速しても、水色のゲージがコンボの表示と重ならないこと（照準の上に出ること）
