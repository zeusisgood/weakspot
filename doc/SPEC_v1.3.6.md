# 弱点破壊 Mod 追加仕様書（v1.3.6）

`SPEC_v1.3.5.md`（Mod 1.3.5）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/SPEC_v1.3.6.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.3.5 がリリース済み。1.3.5 の内容を土台にする
- 内容: **機械の加速と成長**の弱点のマークも、他のプレイヤーに見せる
- この仕様書の内容は、Mod のバージョン **1.3.6** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.3.5 → **1.3.6**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.3,1.4)`）は、変えない。1.3.x 同士は、互いに接続できる
- **パッチなので、互換性を破る変更を入れない**。今ある `MarkerMessage` / `OtherMarkerMessage`（ブロックの位置・面・(u, v)）を、そのまま使う

## 1. 問題

他のプレイヤーが機械の加速の弱点に当てているとき、そのマークが見えない（ユーザーの報告）。1.1.0 から、他のプレイヤーに送るマークは採掘だけ（1.2.0 で動物を足した）だったため。

## 2. 変更

- 自分の**機械・成長**の弱点が出た・動いた・消えたときも、採掘と同じく、マークを送る（`OtherMarkers.sendOwn`。送る頻度・範囲 `markerShareRange`・時間切れは今までどおり）
- 受け取る側は、今までどおり、ブロックの当たり判定の箱と、届いた面・位置から、マークを描く（採掘のマークと同じ扱い。形・色・濃さは各自の設定）
  - 受け取る側の変更は要らないので、**マークを出す側が 1.3.6 なら**、見る側は 1.3.0〜1.3.5 のままでも見える
  - 成長のマークの大きさは、受け取る側が採掘と同じ計算（`weakSpotMinRadius`）で決めるので、サーバーの設定で `growthMinRadius` を `weakSpotMinRadius` より大きくしているときだけ、本人の弱点より少し小さく見える（初期値ではどちらも 0.08 で同じ）
- 釣り・弓・近接のマークは、今までどおり見せない

## 3. README に書くこと

- 「他のプレイヤーの弱点マーク」の節を、採掘・動物・機械・成長のマークが見える、に直す（釣り・弓・近接は見えない）
- 「最新版」の行を 1.3.6 にし、「更新履歴」に 1.3.6 を追加する（通信内容は変わっていない）
- README の「開発」の節の仕様書へのリンクと、`CLAUDE.md` の「仕様の正本」の一覧に、`doc/SPEC_v1.3.6.md` を足す

## 4. ユーザーに確認してもらうこと

- マルチプレイで、他のプレイヤーが機械（かまどなど）や作物の弱点に当てているとき、そのマークが見え、当てるたびに動くこと。やめると消えること
