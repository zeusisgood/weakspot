# 弱点破壊 Mod 追加仕様書（v1.3.5）

`SPEC_v1.3.4.md`（Mod 1.3.4）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/SPEC_v1.3.5.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.3.4 がリリース済み。1.3.4 の内容を土台にする
- 内容: 近接の弱点を、攻撃が届く前の**遠く（16 ブロック）から**見えるようにする
- この仕様書の内容は、Mod のバージョン **1.3.5** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.3.4 → **1.3.5**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.3,1.4)`）は、変えない。1.3.x 同士は、互いに接続できる
- **パッチなので、互換性を破る変更を入れない**。クライアントの表示だけを変える。距離はコード内の定数にする（設定は足さない）

## 1. 問題

近接の弱点は、バニラの「照準の先の敵」（攻撃が届く距離、約 3 ブロック）でしか出ないので、近づくと爆発するクリーパーなどは、弱点を見てから狙う余裕がない（ユーザーの報告）。

## 2. 変更

- 近接の弱点を出す敵を、クライアントが自分で探す。視線の先 **16 ブロック**以内で、一番手前の当たり判定のある生き物（バニラの照準と同じ選び方。スペクテイターは除く）が、近接の対象（1.3.0 §2.1）なら、弱点を出す
  - 敵との間にブロックがあるときは出さない（バニラの照準と同じく、草などの当たり判定のないブロックも遮る）
  - 手前に対象でない生き物（牛など）がいるときは出さない
- 出す面・範囲（1.3.1）・面の選び直し（見えている間は変えない）は、今までどおり。遠くで出た弱点は、近づいても同じ位置に残る
- **当てられるのは、今までどおり攻撃が届く距離だけ**（バニラの照準の先の敵が、弱点の敵で、照準の点が弱点に入っているとき）。遠くの弱点は見えるだけ
- 弱点の大きさは変えない（遠くでは小さく見える。ユーザーの判断）
- 出す条件（右クリック中・採掘中・クリエイティブでは出さない、攻撃のゲージが溜まっていない間は薄い）は、今までどおり
- ほかの弱点（動物など）の出方は変えない

## 3. README に書くこと

- 近接の弱点の説明を「攻撃が届く距離で」から「16 ブロック先の敵に照準を合わせると弱点が出る。当てられるのは攻撃が届く距離だけ」に直す
- 「最新版」の行を 1.3.5 にし、「更新履歴」に 1.3.5 を追加する（通信内容は変わっていない）
- README の「開発」の節の仕様書へのリンクと、`CLAUDE.md` の「仕様の正本」の一覧に、`doc/SPEC_v1.3.5.md` を足す

## 4. ユーザーに確認してもらうこと

- 10〜16 ブロック先のクリーパー・ゾンビに照準を合わせると、弱点が出ること。近づいても同じ位置に残り、届く距離で殴るとクリティカルになること
- 壁の向こうの敵や、手前に牛がいるときは、弱点が出ないこと
