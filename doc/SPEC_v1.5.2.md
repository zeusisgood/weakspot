# 弱点破壊 Mod 追加仕様書（v1.5.2）

`SPEC_v1.5.1.md`（Mod 1.5.1）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/SPEC_v1.5.2.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.5.1 がリリース済み。1.5.1 の内容を土台にする
- 内容: ディスペンサー・ドロッパーの連射（1.4.4）を分かりやすくする。①余分の発射を 2 tick ごとに分けて出す（音と煙が分かれる）。②狙っている間、HUD に「発射 ×n」を出す
- この仕様書の内容は、Mod のバージョン **1.5.2** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.5.1 → **1.5.2**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.5,1.6)`）は、変えない
- **パッチなので、互換性を破る変更を入れない**。パケット・`SyncedSettings`・保存データ・設定は変えない。発射の回数の計算（`ScheduledBoost.dispenseCount`）も変えない

## 1. 連射の間を空ける（サーバー）

- 今は、前倒しで動かしたときに、バニラの発射（1 発目）と余分の発射を**同じ tick にまとめて**出している。これを、余分の発射を **2 tick ごとに 1 発ずつ**出すように変える
  - 例: 3 発なら、0 tick 目・2 tick 目・4 tick 目。5 発なら 8 tick 目まで
- 残りの発射は、ディスペンサーの位置ごとにメモリに持つ（`server/ScheduledTicks`。ワールドの tick の最後に出す）
  - 出すときに、そのブロックが同じディスペンサー（ドロッパー）のままで、読み込まれていることを確かめる。違えば残りを捨てる
  - 出し切る前に、そのディスペンサーがまた前倒しで動いたら（次の信号）、**残りを捨てて**、新しい信号の分から出し直す
  - 加速が切れても（叩くのをやめても）、すでに決まった残りの発射は出す
  - サーバーが止まったら捨てる（`MachineAccelerator.clear` と同じとき）
- 間隔（2 tick）は `ScheduledBoost.BURST_INTERVAL_TICKS` に置く

## 2. HUD の「発射 ×n」（クライアント）

- ディスペンサー・ドロッパー（`BlockDispenser` とそれを継承したブロック）の機械の弱点に照準が合っている間は、コンボの数字の下の「機械 ×n」の代わりに「**発射 ×n**」（英語は「**Shots ×n**」）を出す
  - n は、1 回の信号での発射の回数。クライアントのコンボの掛け数から `ScheduledBoost.dispenseCountForFactor`（= min(5, floor(1 + 掛け数))）で求める。初期値では、コンボ 1〜99 で ×2、100〜499 で ×3、500〜999 で ×4、1000〜 で ×5
  - サーバーの上限の設定（`machineBoostMaxMultiplier`）で倍率が抑えられているときは、実際の回数が表示より少ないことがある（「機械 ×n」と同じく、サーバーの倍率はクライアントに届いていないため）
- 「機械 ×n」は掛け数が ×1.0 のときは出さないが、「発射 ×n」は ×2 から出す（コンボの数字と同じく、コンボが 2 以上のとき）
- 回数が上がった瞬間は光らせる（「機械 ×n」の掛け数が上がったときと同じ光り方）
- 画面の文字列は `en_us.lang` と `ja_jp.lang` の両方に足す

- ガイドの本は変えない（5 ページ目の「レッドストーンの部品も速くできます」のままでよい）

## 5. ユーザーに確認してもらうこと

- クロックにつないだディスペンサーを叩くと、「ダダッ」と音と煙が分かれて出ること。矢が少しずつずれて飛ぶこと
- ディスペンサーを狙っている間、コンボの下に「発射 ×2」が出て、コンボ 100 で「×3」になって光ること
- 普通の機械（かまど）では、今までどおり「機械 ×n」が出ること
