# 弱点破壊 Mod 追加仕様書（v1.3.7）

`SPEC_v1.3.6.md`（Mod 1.3.6）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/SPEC_v1.3.7.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860（IC2 は任意。入っていなければ何も起きない）
- 前提: 1.3.6 がリリース済み。1.3.6 の内容を土台にする
- 内容: **IC2 のゴムの木**（`ic2:rubber_wood`）の、樹液の穴（乾いた穴）の再生を、成長の弱点で早める
- この仕様書の内容は、Mod のバージョン **1.3.7** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.3.6 → **1.3.7**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.3,1.4)`）は、変えない。1.3.x 同士は、互いに接続できる
- **パッチなので、互換性を破る変更を入れない**。パケット・`SyncedSettings` の形は変えない。設定 `growthExtraBlocks` の初期値に1つ足すだけ（キーの意味は変わらない）
- IC2 のクラスには依存しない（ブロックの登録名とプロパティの名前だけで判定する）

## 1. IC2 のゴムの木の仕組み（IC2 2.8.222-ex112 で確かめた）

- 登録名 `ic2:rubber_wood`、プロパティ `state`（`plain_y` / `plain_x` / `plain_z`、`dry_north` / `dry_south` / `dry_west` / `dry_east`、`wet_north` など）
- `dry_*` は、ツリータップで樹液を取ったあとの乾いた穴。`randomTick` のたびに 1/7 の確率で、同じ向きの `wet_*`（樹液が取れる穴）に戻る

## 2. 変更

- 成長の弱点の追加リストの植物（1.1.2・1.2.0）に、**ゴムの木の乾いた穴**を足す
  - 対象: 登録名が `ic2:rubber_wood` で、プロパティ `state` の値が `dry_` で始まるブロック（乾いた穴がある幹）。穴のない幹（`plain_*`）と、樹液が取れる穴（`wet_*`）には出さない
  - 操作は、ほかの成長の弱点と同じ（素手で右クリックを押しっぱなし）
  - 弱点を出す面は、**穴のある面**（`dry_north` なら北の面）。照準がその面に当たっているときだけヒット（成長の弱点と同じ）
  - 効果は、ほかの成長の弱点と同じく、1 ヒットで `randomTick` を `growthTicksPerHit`（初期値 5）回余分に呼ぶ。IC2 の 1/7 の確率で穴が戻る（1 ヒットで約 54%。平均 2 ヒット前後）。穴が戻ったら、対象でなくなるので弱点は消える
  - 成長バーは出さない（年齢のプロパティがないため）
  - 統計の「成長ヒット数」・ヒット音・コンボ・他のプレイヤーへのマークとヒット音は、ほかの成長の弱点と同じ
- 設定 `growthExtraBlocks` の初期値に `ic2:rubber_wood` を足す
  - 既存の設定ファイルは、1.2.2 の移行の仕組み（`configVersion`）で、**3** に上げるときに1回だけ `ic2:rubber_wood` を足す（すでにあれば何もしない。そのあと取り除けば、対象外のまま）
  - `growthExcludedBlocks` に `ic2:rubber_wood` を足すと、対象外になる（ほかの植物と同じ）
- 追加リストのうち、育つ条件をコードで決めてある植物の表（`RightClickTargets.EXTRA_GROWTH_BLOCKS`）に、ゴムの木を足す
- IC2 の版によってプロパティの名前や値が違うときは、弱点が出ないだけにする（エラーにしない）
- 1.3.6 以前のクライアントは、表にゴムの木がないので、弱点が出ない（1.3.7 に更新する）

## 3. README に書くこと

- 成長の弱点の説明に、IC2 のゴムの木の乾いた穴（穴のある面に出る、1 ヒットで約半分の確率で戻る）を足す
- 設定表の `growthExtraBlocks` の初期値に、ゴムの木を足す
- 「最新版」の行を 1.3.7 にし、「更新履歴」に 1.3.7 を追加する（通信内容は変わっていない。弱点を出すには、クライアントも 1.3.7 にする）
- README の「開発」の節の仕様書へのリンクと、`CLAUDE.md` の「仕様の正本」の一覧に、`doc/SPEC_v1.3.7.md` を足す

## 4. ユーザーに確認してもらうこと

- IC2 を入れた環境で、ツリータップで樹液を取ったゴムの木の穴に向かって、素手で右クリックを押しっぱなしにすると、穴のある面に弱点が出ること。当てると数回で穴が戻り（樹液が取れる状態になり）、弱点が消えること
- 穴のない幹、樹液が取れる穴には、弱点が出ないこと
- ツリータップを持った右クリックは、今までどおり樹液が取れること
- 既存の `weakspot.cfg` の `growthExtraBlocks` に、`ic2:rubber_wood` が足されていること（`configVersion=3`）
