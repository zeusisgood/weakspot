# 弱点破壊 Mod 追加仕様書（v1.8.4）

`SPEC_v1.8.3.md`（Mod 1.8.3）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/SPEC_v1.8.4.md`）。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.8.3 がリリース済み
- この仕様書の内容は、Mod のバージョン **1.8.4** として、リリースする

---

## 0. バージョンと互換性

- バージョンは 1.8.3 → **1.8.4**（`build.gradle` の `version` と `WeakSpotMod.VERSION`）
- **通信内容・設定は変わらない**。文章はサーバーが作って送る（下の 2.3）ので、1.8.3 のクライアントでも読める。1.8.x 同士は、そのまま接続できる
- 1.8.3 以前のサーバーにつなぐと、理由は出ない（今までどおり）

## 1. 困っていること（ユーザーの報告）

- 村人を繁殖させたいのに、弱点が出ず、なぜ繁殖しないのかもわからない
- 村人の弱点は「動いているタイマーがあるとき」（子ども・繁殖したあとの待ち時間・ロックされた取引）だけ出る。ふつうの大人の村人には出ない
- 1.12.2 の村人の繁殖は条件が多く（下の 2.2）、止まっている理由がゲームの中で見えない

## 2. 繁殖できない理由を見せる（ユーザーの判断: A のみ。弱点での肩代わりはしない）

### 2.1 出すとき

- **大人の村人**に、**しゃがんで素手で右クリックを押しっぱなし**にして照準を合わせている間（今の村人の弱点と同じ操作）
  - クライアントがサーバーに動物の状態を問い合わせる（`AnimalQueryMessage`。5 tick ごと）ので、サーバーはその返事のときに理由を作る
  - 弱点が出ている村人（待ち時間・ロックされた取引）でも出す
  - 子どもの村人には出さない（弱点で大人にする）
- 動物の弱点を「弱点マーカー」タブでオフにしている・HOME キーで全部オフにしているプレイヤーには出さない（問い合わせが来ないので出ない）
- **アクションバー**（ホットバーの上の 1 行。`sendStatusMessage(…, true)`）に出す。同じ文章は 20 tick に 1 回まで送り直す（文章が変わったらすぐ）

### 2.2 調べる条件（バニラの `EntityAIVillagerMate` と同じ）

上から順に調べ、満たしていないものを**すべて**「・」でつないで 1 行にする。①〜③ で村が見つからないときは、そこで止める。

| # | 条件 | 満たしていないときの文章（日本語） |
|---|---|---|
| ① | 村の中にいる（`getNearestVillage(村人の位置, 0)` が見つかる） | 村の中にいない（ドアのある家が要る） |
| ② | 繁殖の時期（`Village#isMatingSeason`。近くで村人が死ぬと 3 分止まる） | 近くで村人が死んだため、しばらく増えない |
| ③ | ドア: 村人の数 < (int)(ドアの数 × 0.35) | ドアが足りない（村人 n 人・ドア m 枚。あと k 枚） |
| ④ | 待ち時間がない（`getGrowingAge() == 0`） | 待ち時間 あと m:ss（弱点で早められる） ※繁殖の弱点が設定で無効なら「（弱点で早められる）」を付けない |
| ⑤ | その気（`getIsWillingToMate(false)`）か、その気になれる食べ物を持っている | 食べ物が足りない（パン 3 個か、ニンジン・ジャガイモ 12 個） |
| ⑥ | 相手: 8 ブロック（上下 3）以内で**一番近い村人**が、大人で、待ち時間がなく、⑤ を満たす | 近くに相手がいない ／ 相手が子ども ／ 相手が待ち時間中 ／ 相手の食べ物が足りない |

- 全部そろっているとき: 「繁殖の条件はそろっています（少し待つと始まる）」
- 行の頭に「繁殖: 」を付ける（例「繁殖: ドアが足りない（村人 4 人・ドア 8 枚。あと 7 枚）・食べ物が足りない（パン 3 個か、ニンジン・ジャガイモ 12 個）」）

#### 実装時の確認事項（バニラの細かい動き）

- ⑤ の食べ物は、**1 つのスロットに**パン 3 個以上、またはジャガイモ 12 個以上、またはニンジン 12 個以上。バニラの `hasEnoughFoodToBreed` はビートルート 12 個（農民は小麦 9 個）も数えるが、その気にするとき（`getIsWillingToMate(true)`）に減らすのはパン・ジャガイモ・ニンジンだけで、ビートルート・小麦だけではその気にならない。そのため、自分で持ち物を数える（`getVillagerInventory()`）
- `getIsWillingToMate(true)` は食べ物を減らすので呼ばない（`false` で読む）
- ⑥ は、バニラと同じく「一番近い 1 人」だけを見る（`findNearestEntityWithinAABB`、`grow(8, 3, 8)`）。一番近いのが子どもだと、ほかに大人がいても繁殖しない。そのことが文章でわかるようにする
- 取引でもその気になる（取引の初回か 1/5）ので、⑤ で「その気」になっている村人は食べ物がなくても満たす
- ③ の k は、(int)((ドア + k) × 0.35) > 村人 となる一番小さい k。計算は `common/VillagerBreeding` に置き、単体テストを書く（④ の m:ss、⑤ の食べ物の判定、理由の並べ方も）

### 2.3 文章と色

- 文章は `server/ServerLang`（1.5.1 の版の違いの知らせと同じ）で、プレイヤーの言語の翻訳キー（`weakspot.breed.*`）から**サーバーが作り**、`TextComponentString` で送る。1.8.3 以前のクライアントは新しい翻訳キーを持たないため
- 色は、満たしていないものがあるとき 橙 `#FFAA00`（`TextFormatting.GOLD`）、全部そろっているとき 緑 `#55FF55`（`TextFormatting.GREEN`）
  - 1.12.2 のチャット・アクションバーは 16 色だけなので、相談で出した黄 `#FFD23F` は使えない（一番近い `YELLOW` は `#FFFF55`）

## 5. ユーザーに確認してもらうこと

- ふつうの大人の村人に、しゃがんで素手で右クリックを押しっぱなしにすると、アクションバーに「繁殖: …」が出ること
- 理由が合っていること（例: ドアの少ない村で「ドアが足りない」、パンを 3 個投げ渡すと「食べ物が足りない」が消える、近くに子どもの村人がいると「相手が子ども」）
- 全部そろうと緑で「繁殖の条件はそろっています」が出て、しばらくすると子どもが生まれること
- 待ち時間中の村人では、弱点と一緒に「待ち時間 あと m:ss」が出ること
