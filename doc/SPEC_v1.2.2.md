# 弱点破壊 Mod 追加仕様書（v1.2.2）

`SPEC_v1.2.1.md`（Mod 1.2.1）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/SPEC_v1.2.2.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.2.1 がリリース済み。1.2.1 の内容を土台にする
- 内容: キノコにも成長の弱点を出し、当てると確率で巨大キノコに育つようにする（サーバー）
- この仕様書の内容は、Mod のバージョン **1.2.2** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.2.1 → **1.2.2**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.2,1.3)`）は、変えない。1.2.x 同士は、互いに接続できる
- **パッチなので、互換性を破る変更を入れない**（パケット・`SyncedSettings`・保存データ・既存の設定キーの意味は変えない）
- 設定を2つ足す（どちらもサーバーだけが使う。クライアントには送らない）

## 1. 問題

キノコ（茶・赤）は、1.1.0 から設定 `growthExcludedBlocks` の初期値で成長の弱点の対象外にしてあり、弱点が出ない。
また、除外リストから外しても、成長の効果（`randomTick` を余分に呼ぶ）では、キノコは周りに広がるだけで、巨大キノコには育たない。
巨大キノコに育つのは、骨粉と同じ `IGrowable#grow` を呼んだときだけ。

## 2. 変更

### 2.1 対象
- `growthExcludedBlocks` の初期値から `minecraft:brown_mushroom` と `minecraft:red_mushroom` を外す
- キノコ（`BlockMushroom` とその子クラス）は `IGrowable` で、`canGrow` が常に true なので、除外リストになければ、そのまま成長の弱点の対象になる（クライアントの判定は変えない）
- 弱点の面は、当たり判定（0.4 × 0.4 × 0.4）の一番大きい面の規則のまま（同じ大きさなので上面）
- 成長バーは出さない（キノコには `age` がない。現行のまま）

### 2.2 既存の設定ファイルの移行
- `@Config` は、設定ファイルにある値を優先するので、1.2.1 以前に作られた `weakspot.cfg` には、キノコが残る
- そこで、1回だけ、`growthExcludedBlocks` からキノコの2つを取り除く
  - 新しい設定 `configVersion`（初期値 0）を足す。`preInit` で `configVersion` が 1 未満なら、キノコの2つを取り除き、`configVersion` を 1 にして保存する
  - 移行の後に、管理者がキノコを除外リストに書き戻したら、そのまま尊重する（もう取り除かない）
  - 取り除いたときは、ログに1行出す

### 2.3 効果（サーバー、`RightClickHits`）
- キノコへの成長ヒットは、`randomTick` を呼ばない（広がるだけで、育ったように見えないため）
- 代わりに、ヒット1回につき、確率 `mushroomGrowChance`（初期値 **0.1**）で `grow` を1回呼ぶ（骨粉1回と同じ。バニラの骨粉は 40% の確率で `grow` を呼ぶ）
- 育つ条件（下のブロック、上の空き）は、バニラの `grow`（巨大キノコの生成）に任せる。育たなかったときは、バニラと同じく、キノコがそのまま残る
- 検証・統計（成長ヒット数）・連続ヒット数は、ほかの成長ヒットと同じ

## 3. 設定

| キー | 初期値 | 説明 |
|---|---|---|
| `mushroomGrowChance` | 0.1 | `[サーバー]` キノコへの成長ヒット1回で、巨大キノコに育てようとする確率（0〜1）。サーバーだけが使う |
| `configVersion` | 0 | `[内部]` 設定ファイルの移行の済んだ版。書き換えない |

- README の設定表（サーバー）に `mushroomGrowChance` を足し、`growthExcludedBlocks` の初期値の説明からキノコを外す
- `[サーバー]` の項目なので、設定画面の説明は `@Config.Comment` の日本語のまま

## 4. 確認事項

- ビルド・テストが通ること、`runServer` が起動し、移行の後の `weakspot.cfg` で `growthExcludedBlocks` にキノコがなく、`configVersion=1` になっていること
- ゲーム内での確認（ユーザーに依頼）: 暗い場所か菌糸の上のキノコに弱点が出て、当て続けると巨大キノコに育つこと
