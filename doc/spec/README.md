# 仕様書の一覧

この Mod の仕様を版ごとに決めた記録です。各仕様書は、前の版との差分を書いています。

- 今の挙動の正本は、[遊び方](../play.md)・[設定](../config.md)・[仕組み](../architecture.md)（とコード）です。ここにある仕様書は、今のマイナー（1.12.x）の経緯と決定の記録です。仕様書に書かれていないことは、その前の版と、その時点の実装のままです。
- 新しいマイナーを始めたら、前のマイナーの仕様書はここから消し、タグの `doc/spec/` に残します（下の 1.10.2 までと同じ形）。
- 1.11.x の仕様書（1.11.0〜1.11.12）は、タグ [`v1.11.12` の `doc/spec/`](https://github.com/zeusisgood/weakspot/tree/v1.11.12/doc/spec) にあります。
- 1.10.2 までの仕様書（1.0 の MVP から）は、タグ [`v1.10.2` の `doc/spec/`](https://github.com/zeusisgood/weakspot/tree/v1.10.2/doc/spec) にあります。
- 新しい版を作るときは、ここに 1 行足します（新しい版が上）。各版の中身の要約は [../../CHANGELOG.md](../../CHANGELOG.md) を見てください。
