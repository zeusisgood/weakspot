# 仕様書の一覧

この Mod の仕様の正本です。版ごとに、前の版との差分を書いています。

- `SPEC_v1.0.md` が最初の版（MVP）。それ以降の仕様書は、前の版に対する差分です。**仕様書に書かれていないことは、その前の版と、その時点の実装のまま**です。
- 新しい版を作るときは、ここに 1 行足します（新しい版が上）。
- 遊び方の説明は [../play.md](../play.md)、更新の中身の要約は [../../CHANGELOG.md](../../CHANGELOG.md) を見てください。
