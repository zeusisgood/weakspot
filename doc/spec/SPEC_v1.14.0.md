# 弱点破壊 Mod 追加仕様書（v1.14.0）

[`SPEC_v1.13.1.md`](https://github.com/zeusisgood/weakspot/blob/v1.13.1/doc/spec/SPEC_v1.13.1.md)（Mod 1.13.1）に対する**マイナー**の仕様（アイテムの追加: 弱点の欠片・コンボの砂時計・弱点のお守り・弱点の片眼鏡）。ここに書かれていないことは、それと現行実装のままとする。
この仕様書は `doc/spec/SPEC_v1.14.0.md`。

- 対象: Minecraft 1.12.2 / Forge・1.20.1 / Forge・1.21.1 / NeoForge の 3 つ（決まりどおり同じ PR で作る）
- 前提: 1.13.1 が `main` に取り込み済み
- 経緯: 今ある自作のアイテムは「弱点の的」だけで、当て続けても手元に残る物がない。`doc/roadmap.md` の「アイテムの追加」の案 A〜G から選んだ
- ユーザーとの相談で決まったこと:
  - 1.14.0 は手に持つ物の組（案 ②）: A 欠片・B 砂時計・C お守り。C の「移る先の予告」は別のアイテム（片眼鏡）に分ける（Q2）
  - 予告の見せ方は、次の位置に輪郭だけの円をずっと出す（P1）。全種類に出す
  - 欠片の確率は 0.5% × コンボの掛け数。砂時計は猶予 6 秒・効果 5 分・重ねて使うと時間を足す（上限なし）。お守り・片眼鏡の耐久は 500 ヒット分で、欠片で金床の修理。色は相談のときの案のまま
  - D 練習用の的ブロック・E 節目のトロフィー・F 共鳴の水晶・G 弱点のエンチャントは、1.15.0 以降（`doc/roadmap.md` に残す）

## 0. バージョンと互換性

- バージョンを 1.13.1 → **1.14.0**（マイナー）。版を書く 6 か所を揃える
- アイテム・ポーション効果を登録するので、登録の一覧が合わない 1.13.x とは接続できない。範囲を `"[1.14,1.15)"`、1.20.1・1.21.1 の `Network.PROTOCOL` を `"1.14"` にする
- `StatsMessage` に項目（欠片の数）を足す（通信内容の変更。マイナーの中で行う）
- 統計の保存データは NBT のキーを 1 つ足すだけ（古いデータは 0 として読める。止まる条件に当たらない）
- マイナーを上げるので、`PlayerText.of` の `since` が `1.14.0` 以下のものを `TextComponentTranslation`（`Component.translatable`）に直し、`ServerFeatures.since` / `PlayerText.clientSince` の `1.13.x` の分岐を外す
- 前のマイナーの仕様書（1.13.0・1.13.1）を `doc/spec/` から消す（「リリースの手順」どおり）

## 1. 弱点の欠片（`weakspot:shard`）

- 見た目: 欠けた結晶。本体 `#FF5926`（採掘の弱点と同じ）、光る縁 `#FFD23F`。64 個まで重ねられる。クリエイティブのタブは的と同じ（その他）
- 手に入れ方: サーバーが受け付けたヒット（`HitGate.take` を通ったもの）ごとに、確率 **0.5% × コンボの掛け数**（`ComboFactor` の表の値。サーバーのコンボの数で。コンボの上乗せをオフにしたサーバーでも表の値を使う）で 1 個
  - 確率に上限は付けない（100% を超えたら毎回 1 個）
  - 全種類のヒットが対象。的当てのヒットは対象外
  - 採掘の掘る前のヒットは、予約の時点では引かず、掘り始めて確定したときに引く（コンボ・統計と同じ）
  - 乱数はサーバーだけで引く（クライアントから来た数は使わない）
- 渡し方: 直接インベントリに入れる。満杯なら足元に落とす。拾ったときに短い音（1.20.1・1.21.1 はアメジストの欠片の音、1.12.2 は経験値オーブの音）を本人にだけ鳴らす
- 設定: `server.items.shardChance`（初期値 0.5、単位 %、0〜100。0 で出ない）。**サーバー専用**（クライアントに送らない）
- 統計: 手に入れた欠片の累計を種類別の統計と同じ所に保存し（NBT のキー `shards`）、K キーの「統計」タブに「弱点の欠片 ○ 個」を出す。「統計をリセット」で 0 に戻す。節目には入れない
- 進捗: 「初めての欠片」（欠片を初めて持つ。バニラの `inventory_changed` の条件）を `root` の下に 1 つ足す（注: 実装では、ほかの進捗と同じく条件を `minecraft:impossible` にし、サーバーが欠片を渡したときと、ログインのときに累計から与える。あわせて 3 つのレシピをレシピ本に出す）

## 2. コンボの砂時計（`weakspot:combo_hourglass`）

- 見た目: 砂時計。枠 `#C8A060`、砂 `#FFD23F`。16 個まで重ねられる
- 使い方: 手に持って右クリックで 1 つ消費し、ポーション効果「**コンボの猶予**」（`weakspot:combo_grace`。色 `#FFD23F`）を **5 分**付ける（クリエイティブでは減らない）
  - 効果中にもう 1 つ使うと、残り時間に 5 分を足す（上限なし）
  - 効果は死亡で消える（バニラの効果と同じ）。牛乳でも消える
- 効果: コンボが途切れるまでの時間を **2 秒（40 tick）→ 6 秒（120 tick）**にする
  - サーバー（`ComboSync` の途切れの判定）とクライアント（コンボの表示・残り時間のバー・ヒット音の音階が最初に戻るまで）の両方で、自分のプレイヤーにこの効果が付いているかを見る。効果はバニラの仕組みでクライアントにも届くので、通信は足さない
  - 他プレイヤーの頭上のコンボも、その人の効果に合わせて 6 秒で消える
- レシピ（作業台・形あり）で 1 個:

  ```
  ガラス  ガラス  ガラス
  　　　  欠片　  　　　
  ガラス  砂　　  ガラス
  ```

## 3. 弱点のお守り（`weakspot:charm`）

- 見た目: 金の飾りに、中央の宝石。金 `#FFD700`、中央 `#FF3DCB`
- 効果: **オフハンド**に持っている間、自分の全種類の弱点の大きさ（見た目と当たり判定）を **1.25 倍**にする（`spotSize` と掛け合わせる。的当てには効かない）
  - 大きさはクライアントだけで使う（当たり判定はもともとクライアント）。他プレイヤーに見えるマークの大きさも、本人の大きさに合わせる（注: 実装では合わせない。マークの通信に大きさが入っておらず、見る側が自分の設定で描くため。通信を変えずに済ませた）
  - 右クリックでは何もしない（`HeldItems.isFree` の自動判定で、持っていても素手と同じ扱いになる）
- 耐久: **500**。お守りを付けている間、サーバーが受け付けたヒット 1 回ごとに 1 減らす（的当ては減らさない）。残り 1 になったら壊れずに効果が止まる（エリトラと同じ。説明に「修理が必要です」）
- 修理: 金床で欠片 1 個につき 125（4 個で満タン）。同じお守りどうしの合成もバニラどおり
- レシピ（作業台・形あり）で 1 個:

  ```
  　　　  糸　　  　　　
  金　　  欠片　  金
  　　　  金　　  金
  ```

  （注: 形は実装のときに見やすい形へ変えてよい。材料は金インゴット 4・欠片 1・糸 1）（注: 実装では 2 段の「金・糸・金／金・欠片・金」）

## 4. 弱点の片眼鏡（`weakspot:monocle`）

- 見た目: 金の縁の片眼鏡。レンズ `#7FB2FF`、縁 `#FFD700`。頭に付けたときも、顔に片眼鏡の絵が出る（防具の絵）（注: 実装では防具にせず、頭の枠に付けられる普通のアイテムにして、アイテムのモデルの `head` の表示で顔に出す。防具にすると、バニラが傷を受けるたびに耐久を減らして壊すため）
- 付け方: **頭の防具の枠**に付ける（防御力 0。ヘルメットとは同時に付けられない＝守りと予告のどちらを取るか選ぶ）
- 効果: 付けている間、自分の全種類の弱点について、**次に移る位置に輪郭だけの円**を出す（予告）
  - 見た目: その種類の色の、透明度 35% の輪郭（塗りなし）。マーカーの形（ご褒美の「星」など）を選んでいるときは、その形の輪郭
  - 予告の位置には当たり判定がない（当てても何も起きない）
  - 弱点が出た時点で、次の位置も決めておく（今の位置を避ける決め方は今と同じ）。当てると、弱点は予告の位置へ移り、移動が終わったら、その次の予告を出す
  - 狙う面が変わったとき・弱点を出し直したときは、次の位置も選び直す
  - 予告は本人の画面にだけ出す（他プレイヤーのマークには出さない。通信は変わらない）
  - 対象: 全種類（採掘・成長・機械・動物・釣り・弓・近接・乗り物・飲食・睡眠・はしご・エリトラ・エンチャント・収穫・投擲物・ダッシュ・ネザーゲート・泳ぎ・落下）。的当てには出さない
  - 次の位置を決めるのは今もクライアント（`WeakSpotPlacer.place`・`FishingMath.nextSpot`・`AimSpots` / `ScreenSpots` の `placeRandom` など）。決める処理を 1 つ前倒しする形にする
  - HOME キーでオフにしている間・その種類をオフにしている間は出さない
- 耐久・修理: お守りと同じ（500。ヒット 1 回ごとに 1。残り 1 で効果が止まる。金床で欠片 1 個につき 125）
- レシピ（作業台・形あり）で 1 個:

  ```
  　　　  金　　  　　　
  金　　  ガラス  欠片
  　　　  欠片　  　　　
  ```

  （注: 形は実装のときに見やすい形へ変えてよい。材料はガラス 1・金インゴット 2・欠片 2）（注: 実装では「欠片／金・ガラス・金／欠片」の縦の十字）

## 8. ユーザーに確認してもらうこと

- 3 つの版で:
  - いろいろな種類で当て続けると、たまに欠片がインベントリに入り、音が鳴ること。コンボが高いほど出やすいこと
  - 砂時計を使うと効果のアイコンが出て、コンボのバーがゆっくり減り、6 秒近く当てなくても途切れないこと。もう 1 つ使うと残り時間が増えること
  - お守りをオフハンドに持つと弱点が大きく見え、そのとおりに当たること。動物・成長の右クリックが素手と同じに出ること
  - 片眼鏡を付けると、どの種類でも次の位置に薄い輪郭の円が出て、当てるとそこへ移ること。予告の円に照準を合わせても当たらないこと
  - お守り・片眼鏡の耐久が減り、残り 1 で効果が止まり、金床で欠片で直せること
  - 4 つの絵と効果のアイコン、頭に付けた片眼鏡の見た目
- 1.13.x のクライアントで 1.14.0 のサーバーに入れない（版が違う旨が出る）こと
