- バージョンを 1.13.3 → **1.13.4**（パッチ）。版を書く 6 か所を揃える

## 1. 設定の説明に `\n` がそのまま出る（1.20.1・1.21.1）

- 症状: 1.20.1・1.21.1 の設定画面（Mods → 設定 → まとめ）で、項目にカーソルを重ねたときの説明に、改行ではなく `\n` の文字が出る（1.13.2 から。1.12.2 は正しく改行される）
- 原因:
  - `lang/*.json` の設定の説明（`.tooltip`。日英 163 個ずつ、全部が設定の項目の説明）は、改行を JSON の `\\n`、つまり読み込んだあとも「`\` と `n` の 2 文字」で書いている
  - 1.12.2 の Forge の設定画面（`GuiConfig`）は、説明の `\` `n` の 2 文字を改行に直してから出すので、正しく見える
  - 1.20.1・1.21.1 の自前の設定画面（`client/WeakSpotGuiFactory`）は、翻訳をそのまま `Tooltip.create(Component.translatable(…))` に渡すので、2 文字のまま出る
- 修正:
  - `lang/en_us.json`・`lang/ja_jp.json` の `\\n` を、JSON の改行 `\n` に直す（読み込んだあとは本当の改行 1 文字。1 行に 1 つの `"キー": "値"` の形は変わらない）。1.20.1・1.21.1 は、バニラの `Tooltip` が改行で行を分けるので、コードは変えない
  - 1.12.2 の `generateLang`（`mc1.12.2/build.gradle`）は、値の中の改行を `\` `n` の 2 文字にして `.lang` に書く（`.lang` は 1 行 1 キーなので、本当の改行は書けない）。1.12.2 で出来上がる `.lang` の中身は 1.13.3 と同じになる
  - `LangFilesTest.settingTooltipsFollowTheRules` の前置き・後ろの決まり（「…優先されます。」の次と「ファイル: …」の前）を、本当の改行で確かめる
  - 正本に `\\n` が残っていないことを `LangFilesTest` で確かめる（書き戻しの防止）
- 実装のときに確かめること: 1.12.2 の Forge（14.23.5.2860）の `GuiConfigEntries` が説明の `\` `n` を改行に直すこと（jar で）。1.20.1・1.21.1 の `Tooltip` の行分け（`Font.split`）が改行で分けること
- 統計の画面・音の画面の説明（`StatsTab`・`SoundTab`）は、もともと改行を含まないので変わらない

## 2. まとめの一覧が「完了」と重なる（1.20.1・1.21.1）

- 症状: 設定画面の最初の画面（まとめの一覧）で、GUI の大きさが大きい・ウィンドウが低いと、下の段のボタンと「完了」が重なる。さらに低いと、一覧が画面の下にはみ出す
- 原因: まとめ 24 個を 2 列 × 12 段（1 段 24 ピクセル）で並べ、「完了」は一覧の下の位置と画面の下から 28 ピクセルの低いほうに置いている（`GroupsScreen.init`）。一覧に要る高さ（上の余白 40 + 12 段 + 余白 12 ≒ 340）より画面が低い（例: 1080p で GUI の大きさ 3 なら 360、4 なら 270）と、一覧が「完了」の位置を越える
- 修正（`WeakSpotGuiFactory.GroupsScreen`。1.20.1・1.21.1）:
  - 全部入るときは今までどおり（上下の中央に寄せる）
  - 入らないときは、項目の画面（`SettingsScreen`）と同じ形でページに分ける: 一覧は上から 40 ピクセル、1 ページの段数は `max(1, (高さ - 40 - 40) / 24)`、2 列なので 1 ページに段数 × 2 個。画面の下から 28 ピクセルの所に `<`・「完了」・`>`（位置と大きさは項目の画面と同じ。最初・最後のページでは `<`・`>` を押せなくする）
  - ページの番号は画面の大きさを変えても、まとめを開いて戻っても残す（同じ画面の中で持つ。ページ数が減ったら最後のページにする）
  - マルチプレイの断り書き（`weakspot.config.remoteNotice`。上から 24）と一覧（上から 40）は重ならないまま
- 1.12.2 は Forge の設定画面（スクロールする一覧）なので起きない（変えない）

## 5. ユーザーに確認してもらうこと

- 1.21.1（できれば 1.20.1 も）: Mods → 弱点破壊 → 設定 → まとめ（例「コンボ」）で、項目にカーソルを重ねると、説明が `\n` ではなく改行で分かれて出ること（最後の行が「ファイル: …」）。日本語と英語の両方で
- 1.21.1（できれば 1.20.1 も）: GUI の大きさを 3・4（「自動」も）にして設定を開き、まとめのボタンと「完了」が重ならないこと。入らないときは `<`・`>` でページを送れて、全部のまとめが開けること。まとめを開いて戻ると同じページのままであること。ウィンドウの大きさを変えても重ならないこと
- 1.12.2: 設定画面の説明が今までどおり改行で分かれて出ること（`\n` が出ないこと）
