## 0. バージョンと互換性

- バージョンは 1.11.0 → **1.11.1**（`build.gradle` の `version` と `WeakSpotMod.VERSION`）。`ACCEPTED_VERSIONS` は `[1.11,1.12)` のまま
- 通信内容・保存データの形式は変わらない。1.11.x 同士はそのまま接続できる
  - 1 の音階の往復はクライアントだけの設定（`SyncedSettings` に入れない）
  - 2・3 はサーバーだけの設定・コマンド（的当てを始めるかはもともとサーバーが決めている。`TargetRounds.start`）。クライアントに送らない
- 内容は 3 つ: ヒット音の音階の往復（1）・的当てを止めるサーバー設定（2）・的当ての記録を消す管理コマンド（3）
- 1.11.0 の動作確認はすべて済み（ユーザー）。的当ての数字（大きさ・距離・動きの速さ・ご褒美のしきい値 15・30・45・60）は変えない
- 移植の下ごしらえ（`common/` の切り出し・`mc1.12.2/` への移動・CI の matrix）は、この版に入れず、別の作業にする（§6）

## 1. ヒット音の音階の往復（`common/HitPitch`・`client/HitSounds`）

### 1.1 やりたいこと

- 今は、連続ヒットで長音階を下のドから上のドまで上がり、9 回目で下のドに戻る（ド レ ミ ファ ソ ラ シ ド｜ド レ …）
- 設定で「往復」を選ぶと、上のドまで上がったら下がる（ド レ ミ ファ ソ ラ シ ド シ ラ ソ ファ ミ レ｜ド レ …）。1 周は 14 音（上のドと下のドは 1 回ずつ）
- **初期値は今のまま**（戻る）

### 1.2 設定（`client.sound`）

| キー | 型 | 初期値 | 説明 |
|---|---|---|---|
| `hitScaleBounce` | boolean | `false` | [クライアント] ヒット音の音階を、上のドまで上がったら下がる往復にする（オフなら下のドに戻る） |

- 設定画面は `SettingGroups` の「音」のまとめ（`hitChordEnabled` の下）。日英の名前と説明（クライアントの項目なので断り書きなし）
  - 名前（仮）: 「音階を往復」 / "Bounce hit scale"
- `doc/config.md` の「音」の表に 1 行

### 1.3 決まり

- `HitPitch` に、連続ヒット数から音階の度数（0〜7）を出す計算を 1 か所にまとめ、`forStreak`・`forHit`・`resolveFor` が使う。往復かどうかは引数で渡す（`common/` は設定を読まない）
  - 戻る: `(streak - 1) % 8`
  - 往復: `i = (streak - 1) % 14`、`i <= 7 ? i : 14 - i`
- 和音（`hitChordEnabled`）・sus4 の解決の音・300 からのベルは、旋律の度数に対して今までどおり重ねる（下がっている間も、旋律の下に同じ形で重ねる）
- 効く所:
  - 自分のヒット音（`HitSounds.playHit`）
  - ほかのプレイヤーのヒット音（`playOther`。聞く側の設定で決める。的当ての近くの人の音も同じ）
  - 「音」タブの「音階を試聴」: 往復ならド〜上のド〜レまで（14 音、続けて下のドで 15 音）を鳴らす
- 変えない所: コンボの段階・節目の駆け上がり（`accentScale`・`twoOctave`）、コンボの節目の和音（`ComboEffects`）、落下の演出の音、コンボが切れた音
- 単体テスト（`HitPitchTest`）: 往復の 1 周の度数の並び（1〜15 回目）、戻るときは今と同じ値になること

## 2. 的当てを止めるサーバー設定（`server.general`）

### 2.1 やりたいこと

- 大きなサーバーで、的当ての告知やランキングを止めたい管理者向けに、的当てそのものをオフにできるようにする

### 2.2 設定

| キー | 型 | 初期値 | 説明 |
|---|---|---|---|
| `targetPracticeEnabled` | boolean | `true` | [サーバー] 「弱点の的」で的当てを始められるか |

- 設定画面は `SettingGroups` の「共通」のまとめ。日英の名前と説明（「マルチプレイ時、サーバー側設定が優先されます。」で始め、最後の行に「ファイル: server.general.targetPracticeEnabled」）
- **`SyncedSettings` には入れない**（クライアントは知らなくても困らない。通信を変えない）

### 2.3 オフのとき

- 「弱点の的」を右クリックしても始まらない（`TargetRounds.start` が false を返すので、的は減らない）
- 右クリックしたプレイヤーに、アクションバーで「このサーバーでは的当てが無効です」（`PlayerText.of(player, "1.11.1", "weakspot.target.disabled")`。1.11.0 のクライアントには `ServerLang` の文章）。押しっぱなしで何度も届くので、同じ人には 1 秒（20 tick）に 1 回まで
- 初回ログインの的の配布（3 つ）は、オフでもする（オンに戻したときに遊べるように。ようこそのメッセージも今のまま）
- オフにした瞬間に遊んでいるラウンドは、最後まで続けて記録する（途中で切らない）
- 記録・`/weakspot top target`・K キーの「的当て」タブ・ご褒美は今のまま見られる（過去の記録は残る）
- `/weakspot reload` で切り替わる

## 3. 的当ての記録を消す管理コマンド（`server/WeakSpotCommand`）

### 3.1 やりたいこと

- 改造クライアントなどでの不正な記録を、管理者が消せるようにする（1.11.0 では、クライアントの「当てた」を信じているため。`doc/roadmap.md`）

### 3.2 コマンド

- `/weakspot resettarget <プレイヤー>`（OP だけ。ほかの管理のサブコマンドと同じく `execute` で確かめる）
- 消すもの: 的当ての自己ベスト（`targetBest`）と回数（`targetRounds`）を 0 に。ほかの統計は消さない
- 順位（`Leaderboard`）の的当ての値も 0 にする。**オフラインの人も**名前で指定できる（`Leaderboard` にある名前から探す。順位の値はすぐ 0 にし、本人の累計は次のログインのときに 0 にする。待っている人の一覧は `Leaderboard` の保存データに項目を足して覚える。古い版で読んでも無視されるだけ）
- そのプレイヤーがラウンド中なら、そのラウンドはやめる（記録しない）
- 結果: 実行した人に「〇〇 の的当ての記録を消しました」。消された本人には知らせない（騒ぎにしないため）
- 消したことで、ご褒美（星・銀のきらめき・金の粒・虹）は解放されていない状態に戻る（選んでいたら、マーカーは初期の色・形に戻る）。進捗（的当ての 4 段階）は取り消さない（バニラの進捗は取り消しを想定していないため）
- 名前の補完: オンラインの人と、`Leaderboard` にある名前
- `/weakspot` の使い方の表示（`weakspot.command.usage`）に足す。`doc/config.md` の「管理コマンド（サーバー）」の表に 1 行

## 6. この版に入れないもの

| もの | 理由 | どうするか |
|---|---|---|
| 移植の下ごしらえ（`common/` の切り出し・`mc1.12.2/` への `git mv`・CI の matrix） | jar の中身は変わらず、ファイルの移動が大きい。ほかの変更と混ぜると差分が読めない | 1.11.1 のリリースのあと、開いている PR がない時期に、版を上げない別の PR で |
| 的当てのペース表示 | 自己ベストのときの秒ごとのヒット数を、サーバーで覚えて送る必要がある（通信が変わる → マイナー） | 保留（移植のあとに相談） |
| 照準のまわりの弱点の基準の向き | 遊んで気になったら（ユーザーの判断: メモ） | 保留のまま |
| 的当ての不正対策（案 A） | 手間が大きい。公開サーバーで遊ぶ予定が出てから。当面は 3 のコマンドで対処 | 保留のまま |

## 7. ユーザーに確認してもらうこと

- 「音階を往復」をオンにすると、ヒット音が上のドから下がっていくこと。和音・ベル（コンボ 300 から）も自然に聞こえるか。オフなら今までどおり
- 「音」タブの音階の試聴が、往復のときは上がって下がること
- ほかのプレイヤーのヒット音も、自分の設定で往復になること
- `targetPracticeEnabled` を `false` にして `/weakspot reload` すると、的を右クリックしても始まらず、的が減らず、アクションバーに案内が出ること
- `/weakspot resettarget <名前>` で、その人の自己ベストと回数が 0 になり、`/weakspot top target` と K キーの「的当て」タブから消えること。オフラインの人も消せて、次にログインしたとき本人の記録も 0 になっていること
