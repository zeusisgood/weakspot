# 弱点破壊 Mod 追加仕様書（v1.11.1）

`SPEC_v1.11.0.md`（Mod 1.11.0）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
この仕様書は `doc/spec/SPEC_v1.11.1.md`。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.11.0 がリリース済み
- この仕様書の内容は、Mod のバージョン **1.11.1** として、リリースする

---

## 0. バージョンと互換性

- バージョンは 1.11.0 → **1.11.1**（`build.gradle` の `version` と `WeakSpotMod.VERSION`）
- クライアントの中だけの変更。通信内容・保存データは変わらない。1.11.x 同士はそのまま接続できる
- 設定はクライアントの項目を 3 つ足すだけ（名前の変更・削除はない）。`configVersion` は上げない（足した項目は初期値で入る）

## 1. やりたいこと（ユーザーの判断）

- ヒット音の音階の鳴らし方を、各自が選べるようにする（1.11.0 のあとの相談。ユーザーの判断: 案 A・B・C）
  - **A 音階の動き**: 上がりきったら最低音に戻る（今）か、上がったら下がる**往復**か
  - **B 音階の種類**: 長音階（今）・**ペンタトニック**（ド レ ミ ソ ラ。どこで途切れても濁らない）・**短調**（ド レ ミ♭ ファ ソ ラ♭ シ♭。暗めの雰囲気）
  - **C 音域**: 1 オクターブ（今。ピッチ 1.0〜2.0）か、**2 オクターブ**（0.5〜2.0。往復が長くなり、高いコンボほど伸びる感じ）
- 初期値は 3 つとも今のまま（鳴り方は、設定を変えない限り 1.11.0 と同じ）
- 種類ごとの楽器（案 D）・演出の音の音量を別にする（案 E）は見送り（`doc/roadmap.md` にメモ）

## 2. 設定（`client.sound`）

| キー | 初期値 | 側 | 説明 |
|---|---|---|---|
| `hitScaleDirection` | `UP` | クライアント | 音階の動き。`UP`（上がりきったら最低音に戻る）／`UP_DOWN`（上がったら下がる往復） |
| `hitScaleType` | `MAJOR` | クライアント | 音階の種類。`MAJOR`（長音階）／`PENTATONIC`（ペンタトニック）／`MINOR`（短調。自然的短音階） |
| `hitScaleOctaves` | 1 | クライアント | 音域（1〜2 オクターブ）。2 なら 1 つ下のオクターブ（ピッチ 0.5）から始める |

- 3 つともクライアントの項目（`SyncedSettings` には入れない）。`SettingGroups` の「音」のまとめ（`hitChordEnabled` のあと）、`doc/config.md` の「音」の表、日英の lang の名前と説明（`.tooltip`）を足す
- K キーの「サウンド」タブに、3 つの切り替えボタンを足す（押すたびに次の値。今の楽器のボタンと同じ形）。音階の試聴（今ある「音階を鳴らす」）は、今の設定で 1 往復分（往復なら上がって下がるまで）を鳴らす

## 3. 鳴らし方（`common/HitPitch`）

- 選んだ音階の 1 オクターブの音（上のドを含む）: 長音階 8 音（0, 2, 4, 5, 7, 9, 11, 12 半音）、ペンタトニック 6 音（0, 2, 4, 7, 9, 12）、短調 8 音（0, 2, 3, 5, 7, 8, 10, 12）
- 音域が 2 オクターブなら、下のオクターブ（ピッチ 0.5 のド）から上のド（2.0）まで、つなげた並び（長音階・短調は 15 音、ペンタトニックは 11 音）
- 連続ヒット数（1 始まり）から、その並びの何番目を鳴らすか:
  - `UP`: 最低音 → 最高音 → 最低音に戻る（今と同じ。並びの長さで繰り返す）
  - `UP_DOWN`: 最低音 → 最高音 → 最低音 → …（両端は 1 回だけ鳴らす。周期は 2 ×（並びの長さ − 1））
- **和音**（`hitChordEnabled`）: 旋律の何度下を重ねるか（コンボの段階ごとの形。1.11.0 のまま）を、**選んだ音階の中で数える**（短調なら短 3 度、ペンタトニックなら 5 音の中で数える）。ピッチ 0.5 より低くなる音は、0.5 以上になるまでオクターブ上げる（2 オクターブの下のほうで和音が鳴るとき）
- **選んだ音階の種類**は、コンボの節目・累計の節目の駆け上がり（`accentScale`・2 オクターブの駆け上がり）、途切れたときの下がる 2 音、sus4 の解決の音にも使う（雰囲気を揃える）。音階の動き（往復）と音域は、ヒット音だけに使う（駆け上がりは今の長さのまま）
- **ほかの人のヒット音**と**的当てのヒット音**も、聞く人・遊ぶ人の設定で鳴らす（サーバーから届くのは連続ヒット数だけなので、通信は変わらない）
- ベル（300 から）・音量・楽器は今のまま

## 6. ユーザーに確認してもらうこと

- 初期値のままでは、1.11.0 と同じ鳴り方であること
- 「サウンド」タブで、往復・ペンタトニック・短調・2 オクターブを切り替えて試聴でき、実際のヒット音（採掘・照準の種類・的当て）も変わること
- 和音（コンボ 25 から）が、短調・ペンタトニックでも濁らずに聞こえるか。2 オクターブの低い所の和音が低すぎないか
- ほかの人のヒット音も、自分の設定の音階で鳴ること
- 節目の駆け上がり・途切れたときの音が、選んだ音階の種類で鳴ること
