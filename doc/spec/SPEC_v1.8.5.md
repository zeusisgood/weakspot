# 弱点破壊 Mod 追加仕様書（v1.8.5）

`SPEC_v1.8.4.md`（Mod 1.8.4）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/spec/SPEC_v1.8.5.md`）。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.8.4 がリリース済み
- この仕様書の内容は、Mod のバージョン **1.8.5** として、リリースする

---

## 0. バージョンと互換性

- バージョンは 1.8.4 → **1.8.5**（`build.gradle` の `version` と `WeakSpotMod.VERSION`）
- **通信内容・設定は変わらない**。1.8.x 同士は、そのまま接続できる
- 本はサーバーが作り、文章（翻訳キー）は読む人のクライアントが訳す。**1.8.4 以前のクライアントが 1.8.5 のサーバーで渡された本を読むと、新しい翻訳キーを持たないので、キーのまま出る**（README に書く）。K キーのメニューの「ガイド」は自分のクライアントで作るので、いつも読める

## 1. 困っていること（ユーザーの報告）

### 2.2 1 ページの形

```
近接                          ← 太字・章の色
■ 出るとき                    ← 濃い灰 #555555（DARK_GRAY）
剣か斧を持ち、近くに敵がいる間。
照準の左か右に、銀色の弱点。
■ 当てると
溜めがたまり、次に殴るとクリティカル。
溜めた分だけ強くなる。
■ ヒント
持ち替えると、溜めは消える。

↩ 目次                        ← クリックで目次の最初のページへ
```

- 弱点の種類のページ（採掘・成長・収穫・機械・動物・弓・近接・投げる物・食事・乗り物・はしご・走り・エリトラ・ネザーゲート・釣り・睡眠・エンチャント）は、小見出し「**■ 出るとき**」「**■ 当てると**」「**■ ヒント**」の 3 つ（ヒントは、書くことがなければ省く）
- それ以外のページ（キーとメニュー、コンボ、耐久回復と節目、共通の説明、マルチプレイ、弱点マーカー、困ったとき）は、ページごとに合う小見出しを付ける（例: キーとメニュー → 「■ HOME キー」「■ K キー」）
- 1 ページに入る量: 本の 1 ページは 14 行。見出しと「↩ 目次」を除いて、日本語で 120 字くらいまで、英語で 200 字くらいまで。はみ出さないように、文は短く、箇条書きに近い形にする
- 各ページの一番下に「↩ 目次」（`ClickEvent` の `CHANGE_PAGE`、2 ページ目へ）。表紙と目次のページには付けない

### 2.3 目次

- 3 ページ（2〜4）。章の題（太字・章の色）の下に、ページの名前を 1 行ずつ並べ、**クリックでそのページへ飛ぶ**（`CHANGE_PAGE`）。右にページ番号を出す
  - 2 ページ目: 1〜3 章、3 ページ目: 4 章、4 ページ目: 5・6 章
- 表紙には「次のページから目次」だけ書く

### 2.4 翻訳キー

- 番号のキー（`weakspot.guide.<n>.title` / `.text`）をやめて、名前のキーにする: `weakspot.guide.<ページ>.title` と `weakspot.guide.<ページ>.<小見出し>`（例 `weakspot.guide.melee.title`、`weakspot.guide.melee.when` / `.hit` / `.tip`）、小見出しの文字は `weakspot.guide.head.<小見出し>`、章の題は `weakspot.guide.chapter.<n>`
- ページの並び・章・小見出しは `GuideBook` の表に持つ（`GuideBook.PAGES` はページの一覧にする）
- 古い番号のキーは lang から消す（古い本は 2.5 で差し替える）

### 2.5 今持っている本の差し替え

- 新しい本には NBT に `weakspotGuide`（整数。今回は 2）を入れる
- 古い本（`written_book` で、題と作者が「Weak Spot Mining」、`weakspotGuide` がないか 2 より小さい）は、次のときに新しい本に差し替える（数はそのまま）
  - ログインしたとき、持ち物（メインの持ち物・防具・オフハンド）の中のもの
  - 右クリックで開こうとしたとき（`RightClickItem`、サーバー）。サーバーは差し替えてキャンセルし、クライアントは古い本を開かずに（キャンセル）、その場で作った新しい本を開く（実装で変えた。「もう一度開いてください」の知らせより手間がなく、古いサーバーでも新しい本が読めるため）
- チェストなどにしまった本は、取り出して開こうとしたときに差し替わる

### 2.6 本の中身の見直し

- 今の各ページの文章を、2.2 の形に書き直す。README の今の遊び方と食い違う所（古い数値など）があれば直す
- 題（`TITLE`）は今のまま「Weak Spot Mining」（アイテムの名前として出る）。表紙の題は翻訳キーで各自の言語
