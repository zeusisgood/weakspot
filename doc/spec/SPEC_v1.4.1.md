# 弱点破壊 Mod 追加仕様書（v1.4.1）

`SPEC_v1.4.md`（Mod 1.4.0）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/spec/SPEC_v1.4.1.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.4.0 がリリース済み。1.4.0 の内容を土台にする
- 内容: 遊び方の**ガイドの本**（README から技術的なことを省いたもの）を、初めてのログインで渡す。統計画面から読み直せる
- この仕様書の内容は、Mod のバージョン **1.4.1** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.4.0 → **1.4.1**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.4,1.5)`）は、変えない。1.4.x 同士は、互いに接続できる
- **パッチなので、互換性を破る変更を入れない**。パケットは足さない。保存データは、キーを1つ足すだけ（古い版は無視する）。設定は、サーバーだけが使うもの（送らない）を1つ足す

## 1. 本を渡す

- プレイヤーが、そのワールド（サーバー）に**初めてログインしたとき**に、記入済みの本（`minecraft:written_book`）を1冊渡す
  - 渡したことは、プレイヤーの永続データ（統計と同じ `PlayerPersisted` の `weakspot`）のキー `guideGiven` に記録する（死亡・ディメンション移動で消えない）。1.4.0 以前から遊んでいるプレイヤーにも、1.4.1 で初めてログインしたときに1回渡す
  - 持ち物がいっぱいなら、足元に落とす
- 設定 `giveGuideBook`（初期値 `true`。**サーバーだけが使う**。送らない）が `false` なら渡さない
- 本のタイトルは `Weak Spot Mining`、著者も `Weak Spot Mining`（本のタイトルは翻訳できないため固定）

## 2. 本の中身

- 各ページは、翻訳キーの文章（`weakspot.guide.<n>.title` と `weakspot.guide.<n>.text`）で作る。表示するときに、読む人のクライアントの言語（`ja_jp` / `en_us`）で出る
- キーの名前は、読む人の操作設定から出す（キーバインドの文章。キーを変えていれば、変えたあとのキー）
- 技術的なこと（設定の名前・値、通信、バージョン、仕組み）は書かない。遊び方だけ
- 1ページは、日本語で 150 文字くらいまで（本の1ページに収まる量）

| ページ | 内容 |
|---|---|
| 1 | はじめに（弱点とは、当てると何が起きるか） |
| 2 | 採掘（左クリックの長押し、耐久バー） |
| 3 | 耐久回復と節目 |
| 4 | 作物・苗木の成長（素手で右クリックの押しっぱなし） |
| 5 | 機械の加速（しゃがんで素手で右クリック） |
| 6 | 動物（子ども・繁殖・羊毛・卵・村人） |
| 7 | 釣り（浮きのまわりの弱点を左クリック） |
| 8 | 弓（引きながら照準を合わせる、過剰チャージ） |
| 9 | 近接（敵の弱点を殴るとクリティカル、ゲージが溜まってから） |
| 10 | コンボとヒット音 |
| 11 | キー（一時オフ、統計画面） |
| 12 | マルチプレイ（仲間のマークと音） |

## 3. 読み直し

- 統計画面（K キー）の右上（タブの右）に「ガイド」ボタンを足す。押すと、同じ中身の本を、持っていなくても読める画面で開く（クライアントだけ。サーバーには何も送らない）
- 本をもう一度もらうコマンドは、作らない（ユーザーの判断）

## 4. 今後の決まり（`CLAUDE.md` に書く）

- README の遊び方（プレイヤーから見える動き）を変えたときは、ガイドの本の文章（`en_us.lang` と `ja_jp.lang` の `weakspot.guide.*`）も合わせて直す

## 5. README に書くこと

- 「遊び方」の最初に、初めてのログインでガイドの本がもらえること、統計画面の「ガイド」ボタンで読み直せることを書く
- 設定表（サーバー）に `giveGuideBook` を足す（サーバーだけが使う）
- 「最新版」の行を 1.4.1 にし、「更新履歴」に 1.4.1 を追加する（通信内容は変わっていない）
- README の「開発」の節の仕様書へのリンクと、`CLAUDE.md` の「仕様の正本」の一覧に、`doc/spec/SPEC_v1.4.1.md` を足す

## 6. ユーザーに確認してもらうこと

- 新しいワールドに入ると、ガイドの本を1冊もらえること。出て入り直しても、もう一度はもらえないこと
- 本の文章が、日本語の設定なら日本語、英語なら英語で出ること。1ページに収まっていること（はみ出したら報告する）
- キーのページに、今の操作設定のキー（初期値なら HOME と K）が出ること
- 統計画面の「ガイド」ボタンで、同じ本が開くこと
