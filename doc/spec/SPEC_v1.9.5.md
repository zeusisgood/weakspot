# 弱点破壊 Mod 追加仕様書（v1.9.5）

`SPEC_v1.9.4.md`（Mod 1.9.4）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
この仕様書は `doc/spec/SPEC_v1.9.5.md`。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.9.4 がリリース済み
- この仕様書の内容は、Mod のバージョン **1.9.5** として、リリースする

---

## 0. バージョンと互換性

- バージョンは 1.9.4 → **1.9.5**（`build.gradle` の `version` と `WeakSpotMod.VERSION`）
- 自分のクライアントで鳴らす音だけの変更。通信内容・保存データは変わらない。設定は項目を 1 つ足すだけ（`[クライアント]`）。1.9.x 同士はそのまま接続できる

## 1. やりたいこと（ユーザーの報告と判断）

- 今のヒット音（`HitPitch`: ドレミの 8 音で上がり、上のドで下のドに戻る）は、コンボが 10 でも 100 でも聞こえ方がほぼ同じで、「伸びている」ことが伝わりにくい
- コンボの段階の音（10・25・50 の 1 音、100 の和音）が、ヒット音と同じ楽器・同じ瞬間なので埋もれる
- 250・500・1000 の駆け上がりと、累計の節目の音階も、続けて当てているヒット音に埋もれがち
- 相談の結果（ユーザーの判断）: コンボで和音が厚くなる（S1）、段階の音を別の楽器にする（S2）、説明を足す（S5）、駆け上がりを埋もれないようにする、コンボが切れた音（T1）。自分の音量の初期値（25%）は変えない。音階の往復（T2）は 1.9.5 を聞いてから決める。切れそうなときの音・他のプレイヤーの音の数の上限・段階の画面の演出は見送り

## 2. コンボで和音が厚くなる（S1）

- 自分のヒット音（旋律。今の `HitPitch.forStreak` の音）に、コンボの数に応じて音を重ねる
  - コンボ 1〜24: 旋律の 1 音（今のまま）
  - コンボ 25〜99: 旋律 ＋ **3 度下**（音階で 2 つ下の音）
  - コンボ 100 以上: 旋律 ＋ **3 度下** ＋ **5 度下**（音階で 2 つ・4 つ下の音）
- 区切り（25・100）は、コンボの数字の色の段階（`ComboTier` の橙・虹色）とそろえる
- 重ねる音は旋律より**下**に置く（Minecraft の音のピッチの上限が 2.0 で、旋律の最高音がちょうど 2.0 のため）。旋律は 1.0〜2.0、重ねる音の最低は約 0.67 で、下限 0.5 の中に収まる
- 重ねる音の音量は、旋律の **0.6 倍**（旋律が上に聞こえるように）。楽器は旋律と同じ
- 音の計算（コンボの数 → 鳴らすピッチの一覧）は `common/HitPitch` に置き、単体テストを書く
- 他のプレイヤーのヒット音には重ねない（ユーザーの判断。今のまま 1 音）
- 設定 `hitChordEnabled`（`[クライアント]`、初期値 true）: オフなら重ねない（今の 1 音のまま）。K キーの「サウンド」タブにも切り替えを置く

## 3. 段階の音を別の楽器にする（S2）

- コンボの段階の演出（`ComboEffects`: 10・25・50 の 1 音、100 の和音）の音を、ヒット音の楽器ではなく**ベル**（`BLOCK_NOTE_BELL`）で鳴らす
- 10・25・50 は、1 音から「ド・ミ・ソ」の**分散和音**（1 tick ずつずらす）にする
- 音量は、自分のヒット音の音量の **1.5 倍**（上限 1.0）

## 4. 駆け上がりを埋もれないようにする（ユーザーの報告）

- 対象: コンボの 250・500・1000 の駆け上がり（と 1000 の和音）、累計の節目の音階（`MilestoneEffects`）
- 楽器を**ベル**にし、音量を自分のヒット音の音量の **1.5 倍**（上限 1.0）にする（3 と同じ）
- **駆け上がりが鳴っている間は、自分の通常のヒット音を小さくする**（旋律と重ねる音を **0.3 倍**。鳴らさないのではなく、当てた手応えは残す）。駆け上がりの最後の音の 2 tick 後まで
  - 予約した音（`HitSounds.schedule`）の終わりの tick を覚え、その間の `playOwn` の音量を下げる
- 駆け上がりの速さ（1 音 1 tick）は今のまま
- 試聴（K キーの「サウンド」タブ）の音階はヒット音の楽器のまま

## 4b. コンボが切れた音（T1。ユーザーの判断）

- 今は、コンボが切れても音は鳴らない（画面に「MAX 23」が約 1 秒残るだけ）。採掘に集中していると見落とす
- 自分のコンボが **10 以上**で切れたとき（`HitStreak.expire` が 10 以上を返した tick）、低い下がり調子の 2 音（**ソ → 下のド**。ピッチ 0.75 → 0.5、2 tick あける）を、自分のヒット音の楽器で、音量は自分のヒット音の **0.5 倍**で鳴らす
- 死亡・ディメンションの移動・ワールドを出たときの 0 戻し（`reset`）では鳴らさない
- 他のプレイヤーのコンボが切れたときは鳴らさない
