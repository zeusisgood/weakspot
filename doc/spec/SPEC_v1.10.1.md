# 弱点破壊 Mod 追加仕様書（v1.10.1）【下書き】

この仕様書は `doc/spec/SPEC_v1.10.1.md`。

- 前提: 1.10.0 がリリース済み
- この仕様書の内容は、Mod のバージョン **1.10.1** として、リリースする

## 0. バージョンと互換性

- バージョンは 1.10.0 → **1.10.1**（`build.gradle` の `version` と `WeakSpotMod.VERSION`）
- クライアントの中だけの変更。通信内容・保存データ・設定は変わらない。1.10.x 同士はそのまま接続できる（サーバーのヒットの受け付けは今のまま。1.10.0 のサーバーでも効く）

## 1. やりたいこと（ユーザーの判断）

- クリックで当てる種類（睡眠・釣り・エンチャント）のうち、**睡眠と釣りを「重ねるだけで当たり」**にする（ほかの照準の弱点と同じ遊び方に揃える。連打の手間をなくす）
- **エンチャントはクリックのまま**（重ねるだけにすると、候補を選ぼうとカーソルを動かした途中で引き直され、狙っていた候補が消えるため）
- 相談の結果: 案 1（睡眠・釣りはクリック不要、エンチャントはクリック）。設定で選べる形にはしない

## 2. 睡眠（`client/SleepSpot`・`ScreenSpots`）

- 就寝画面で、**マウスのカーソルがマーカーの円の中に入ったら当たり**（毎フレーム、`DrawScreenEvent.Post` のカーソルの位置で判定）
- 画面の上の種類の共通の土台（`ScreenSpotKind`）に「重ねたら当たりか」（仮の名前 `hitsOnHover()`）を足す。睡眠は true、エンチャントは false（今のクリックの判定のまま）
- ヒットの最小間隔（`sleepMinHitIntervalTicks`）は今のまま効く。当てたら今までどおり次の位置へ移る（前の位置から離れた所）ので、カーソルを置きっぱなしでは続けて当たらない
- 就寝画面を開いた瞬間、カーソルは画面の中央にある（Minecraft が中央に戻す）。マーカーが中央付近に出ると、開いてすぐ 1 回当たることがあるが、害はないのでそのままにする
- 当てるのに左クリックを使わなくなるので、就寝画面のクリックは今までどおりボタン（「ベッドから出る」）やチャット欄に届く（クリックを止める処理は、睡眠では使わない）

## 3. 釣り（`client/FishingSpot`）

- 浮きが魚を待っている間、**照準が弱点に重なったら当たり**（今の「重なっている」の判定 `aimed` のまま。重なったフレームで当てる）
- 釣り竿を持っていることは今までどおりの条件
- ヒットの最小間隔（`fishingMinHitIntervalTicks`）は今のまま。当てたら今までどおり次の位置へ移る
- 左クリックを止める処理（`MouseEvent` のキャンセル）はやめる。釣りの間も、左クリックは通常どおり（ブロックの採掘・攻撃）

## 4. エンチャント

- 変えない（クリックで当てる。当てたクリックはスロットやボタンに届かない）

- `doc/play.md`: 釣り・睡眠の節の見出しと本文（「左クリック」「クリックで当てる」→ 照準・カーソルを重ねるだけ）。見出しを変えると README からのリンク（アンカー）も変わるので合わせる
- `README.md`・`README.en.md` の種類の一覧（釣り・睡眠の行）
