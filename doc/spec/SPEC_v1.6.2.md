# 弱点破壊 Mod 追加仕様書（v1.6.2）

`SPEC_v1.6.1.md`（Mod 1.6.1）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/spec/SPEC_v1.6.2.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.6.1 がリリース済み。1.6.1 の内容を土台にする
- 内容: 寝ている間の弱点（1.6.0）のマーカーを、画面の中央の範囲だけに出す（画面全体に出ると、次のマーカーが遠すぎる、というユーザーの指摘）
- この仕様書の内容は、Mod のバージョン **1.6.2** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.6.1 → **1.6.2**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.6,1.7)`）は、変えない
- **パッチなので、互換性を破る変更を入れない**。マーカーの位置はクライアントだけが決めている（サーバーは位置を確かめない）ので、通信・設定・保存データは変わらない。クライアントだけの変更

## 1. マーカーを出す範囲（`client/SleepSpot`、計算は `common/SleepSpotArea`）

- 今: 画面全体（縁から 24 ピクセル、下の 1/4 を除く）。次のマーカーは、前の位置から画面の高さの 1/4 以上離す
- 変更後: **画面の中央の、幅・高さとも 4 割の範囲**（横は画面の幅の 30〜70%、縦は高さの 30〜70%）。下のボタンとチャット欄（下から 1/4）にはかからない（範囲の下端は、高さの 75% − マーカーの半径まで）
- 次のマーカーは、前の位置から **max(マーカーの半径 × 2.5, 画面の短い辺 × 0.15)** 以上離す（範囲が狭いので、離す距離も縮める。取れなければ、一番離れた位置）
- 範囲と離す距離の計算は `common/SleepSpotArea` に置き、単体テストを書く

- 近すぎて簡単すぎないか（範囲の広さは調整できる）
