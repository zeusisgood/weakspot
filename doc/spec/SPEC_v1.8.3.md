# 弱点破壊 Mod 追加仕様書（v1.8.3）

`SPEC_v1.8.2.md`（Mod 1.8.2）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/spec/SPEC_v1.8.3.md`）。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.8.2 がリリース済み
- この仕様書の内容は、Mod のバージョン **1.8.3** として、リリースする

---

## 0. バージョンと互換性

- バージョンは 1.8.2 → **1.8.3**（`build.gradle` の `version` と `WeakSpotMod.VERSION`）
- **クライアントの画面の文字とボタンだけの変更**。通信内容・設定のキーは変わらない。1.8.x 同士は、そのまま接続できる
- サーバーから送る文字（節目のチャットなど）は翻訳キーなので、表示はクライアントの版の文章になる

## 1. 「弱点マーカー」タブ（K キーの画面）

### 1.1 名前

- タブ「弱点」を「**弱点マーカー**」にする（英語は、タブの幅に入る「**Markers**」）
- README・ガイドの本の「『弱点』タブ」も、すべて「『弱点マーカー』タブ」にする

### 1.2 色と形を前に戻せるようにする（ユーザーの判断: ◀ ボタン）

- 色: `[■][◀][入力欄][▶]`。◀ で 1 つ前の色、▶ で次の色（「初期値」→ 12 色 → 「初期値」の輪。今の色が 12 色にないとき（打ち込んだ色）は、◀ で 12 色の最後、▶ で最初）
- 形: `[◀][● 丸][▶]`。◀ で 1 つ前、▶ で次（丸 → 輪 → ひし形 → 四角 → 丸）。真ん中は押せない表示だけ（押したら ▶ と同じ）
- 行に入るように、形の表示を細くする（全体の幅は今のまま 308 GUI ピクセルに収める）

### 1.3 言い回し

| 今 | 直したあと | 英語 |
|---|---|---|
| 一時オフ中 | すべてオフ中（%s キー） | All off (%s) |
| サーバーで無効 | サーバーでオフ | Off on server（今のまま） |

- `%s` は、弱点のオン・オフのキーの今の割り当て（初期値 HOME）

## 2. ほかの言い回しの直し（ユーザーの判断: 表のとおり）

| 場所 | 今 | 直したあと |
|---|---|---|
| K キーの画面の題 | 弱点の統計 | **弱点破壊** |
| キーの名前（操作設定） | 弱点の統計を開く | **弱点破壊のメニューを開く** |
| 統計の行 | 弱点ヒット数（採掘） | **採掘ヒット数** |
| 統計の行 | 最大連続ヒット数 | **最大コンボ** |
| HOME キーのお知らせ | 弱点: オン／弱点: オフ／弱点: オフ（%s で切り替え） | **弱点（すべて）: オン／オフ／オフ（%s で切り替え）** |
| キーの名前（操作設定） | 弱点のオン・オフ | **弱点のオン・オフ（すべて）** |
| 採掘の節目のタイトル | %s ヒット！ | **採掘 %s ヒット！** |
| 採掘の節目のチャット | [弱点] 弱点ヒットが %s 回に達しました！ | **[弱点] 採掘の弱点ヒットが %s 回に達しました！** |
| エンチャントの注釈 | ◎ に当てると、候補を引き直せます（%s 回） | **マーカーに当てると、候補を引き直せます（%s 回）** |
| 設定画面の注意書き | …サーバーの設定が使われます（音と見た目の設定を除く） | **…サーバーの設定が使われます（各自の設定を除く）** |
| 育たないとき | …何らかの外部要因で育たないようです。まわりの環境を確認してください | **…育ちません。まわりの条件（水・光・空き・土など）を確かめてください** |

- 英語も同じように直す。統計の行の大文字の使い方を「Growth hits」の形（最初だけ大文字）にそろえる（Melee hits、Ladder hits、…、Total hits）
- 統計の説明（ツールチップ）の「弱点ヒット数」の言い方も合わせる

## 5. ユーザーに確認してもらうこと

- K キーの画面の題が「弱点破壊」、タブが「弱点マーカー」になっていること
- 色の ◀ ▶ で前後に切り替えられ、形も ◀ ▶ で前後に切り替えられること。行が画面からはみ出さないこと
- HOME キーで全部オフにすると、タブの上に「すべてオフ中（HOME キー）」と出ること
- 統計の「採掘ヒット数」「最大コンボ」、採掘の節目の「採掘 100 ヒット！」などの新しい言い方
