# 弱点破壊 Mod 追加仕様書（v1.11.4）

この仕様書は `doc/spec/SPEC_v1.11.4.md`。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.11.3 がリリース済み
- この仕様書の内容は、Mod のバージョン **1.11.4** として、リリースする
- 内容は §1・§2 の 2 つだけ（ユーザーの判断）

## 0. バージョンと互換性

- バージョンは 1.11.3 → **1.11.4**（`build.gradle` の `version` と `WeakSpotMod.VERSION`）
- クライアントだけの見た目の修正。通信内容・設定・保存データは変わらない。`ServerFeatures.since` も要らない

## 1. エンチャント画面の案内の文字を読みやすく（ユーザーの判断: 案 B）

- 不具合: エンチャント画面の上の案内（「物を置くと、弱点で候補を引き直せます」・「弱点で候補を引き直せます」・引き直した回数）が、暗い紫に見えて読みにくい（ユーザーのスクリーンショット）
- 原因（見込み）: `EnchantSpot.drawExtra` は `GuiScreenEvent.DrawScreenEvent.Post` で描く。1.12.2 の `GuiContainer.drawScreen` は描き終わりにアイテム用のライティングを有効にしたまま戻るので、文字に陰が付いて暗くなる
- 直し方:
  - ライティングは §2 で `ScreenSpots` の入口でまとめて切る
  - 文字の色は今のまま（エンチャントの弱点の色。初期値 `#B070FF`、「弱点マーカー」タブで変えた色ならその色）
  - 文字の後ろに、文字の幅（左右に 2 ピクセルずつ余白）の**黒の半透明** `#000000`・不透明度 50%（`0x80000000`）の帯を敷く。高さは文字の高さ + 上下 1 ピクセル
- 案 A（ライティングだけ直す）・案 C（白 `#FFFFFF` の文字 + 黒の帯）は選ばなかった

## 2. エンチャント画面の弱点の円も、同じ原因で暗くならないように

- 弱点の円・残像（`ScreenSpots.draw` → `ScreenProjection.drawMarker`）も同じ `DrawScreenEvent.Post` で描いていて、`HudSpot.beginOverlay` はライティングを切らない。コンテナ画面（エンチャント台）では円も暗く描かれているはず（寝ているときの画面はコンテナではないので影響なし）
- 直し方: `ScreenSpots.onDrawScreen` の入口で、ライティングが有効か（`GL11.glIsEnabled(GL11.GL_LIGHTING)`）を覚えてから切り（`GlStateManager.disableLighting`）、円・残像・§1 の文字を描き終えたら、有効だったときだけ戻す（`enableLighting`。ほかの Mod の描画の状態を変えない）
- `HudSpot.beginOverlay` は変えない（ワールドの HUD では、もともとライティングは切れている）
- 色・濃さ・大きさの設定は変えない。直ったあとの円は、ほかの種類の弱点と同じ明るさになる

- エンチャント台を開くと、上の案内が明るい紫 `#B070FF` で、黒の半透明の帯の上に出る（草・石・夜など、どの背景でも読める）
- 台に物を置く前・置いたあと・引き直したあとの 3 つの文が、どれも同じ見た目

- ベッドで寝ているときの画面の弱点（睡眠）の見た目が変わっていない
- ほかの画面（かまど・チェストなど）やほかの Mod の表示の色が変わっていない
