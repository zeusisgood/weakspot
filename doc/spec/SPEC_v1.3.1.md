# 弱点破壊 Mod 追加仕様書（v1.3.1）

`SPEC_v1.3.md`（Mod 1.3.0）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/spec/SPEC_v1.3.1.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.3.0 がリリース済み。1.3.0 の内容を土台にする
- 内容: 近接の弱点を、敵の**頭・首・胴体のあたり**（当たり判定の箱の上のほう）にだけ出す
- この仕様書の内容は、Mod のバージョン **1.3.1** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.3.0 → **1.3.1**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.3,1.4)`）は、変えない。1.3.x 同士は、互いに接続できる
- **パッチなので、互換性を破る変更を入れない**（パケット・`SyncedSettings`・保存データ・設定キーは変えない）。範囲の比率は、設定にせず、コード内の定数にする

## 1. 問題

近接の弱点（1.3.0 §2）は、敵の当たり判定の箱の面のどこにでも出るので、足先に出ると狙いにくい（ユーザーの報告）。

## 2. 変更

近接の弱点を出す範囲（ヒットのあとに移る先も同じ）を、面ごとに次のようにする。

| 面 | 範囲 |
|---|---|
| 側面（前・後ろ・横） | 箱の高さの**下 40% を除いた**、上の 60%（頭・首・胴体・腕） |
| 上面（見下ろしたときの頭のてっぺん） | 今までどおり、面の全体 |
| 底面（見上げたとき） | **出さない** |

- 40% は、バニラのゾンビ・スケルトンの脚（高さの約 37%）を外す値。クリーパーは胴体の下の端が少し削れる、クモ・スライムは体の上のほうになる
- 範囲が狭い（子どものゾンビなど）ときは、ほかの弱点と同じく、範囲の大きさに合わせて弱点の大きさなどを決める（`WeakSpotPlacer.layout`）。範囲の短い辺が `minFaceSize` 未満なら、その面には出さない
- 底面に照準が当たっているときは、弱点を出さない（ほかの面に照準を移すと出る）
- 動物の弱点（`HitKind.ANIMAL`）の範囲は、変えない（面の全体のまま）
- 当たり判定・クリティカルの付け方・サーバーでの確認は、変えない（サーバーは弱点の位置を確かめない）

## 3. 単体テスト（`common/` の純粋な計算）

- 側面の範囲が、高さの下 40% を除いた上の 60% になること（幅は変わらない）
- 上面は、面の全体になること
- 底面は、範囲なし（出さない）になること

## 4. README に書くこと

- 近接の弱点の説明に、「頭・首・胴体のあたり（箱の上の 6 割）にだけ出る。見上げた底面には出ない」を足す
- 「最新版」の行を 1.3.1 にし、「更新履歴」に 1.3.1 を追加する（通信内容は変わっていない。1.3.x 同士は、そのまま接続できる）
- README の「開発」の節の仕様書へのリンクと、`CLAUDE.md` の「仕様の正本」の一覧に、`doc/spec/SPEC_v1.3.1.md` を足す

## 5. ユーザーに確認してもらうこと

- ゾンビ・スケルトンの側面で、弱点が脚に出ず、頭・胴体のあたりに出ること。ヒットのあとも、その範囲の中で動くこと
- 見下ろしたとき、頭のてっぺんに出ること。見上げたとき（底面）には出ないこと
- 子どものゾンビ・クモ・スライム・クリーパーでも、弱点が出て当てられること
