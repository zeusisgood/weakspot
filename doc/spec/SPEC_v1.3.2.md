# 弱点破壊 Mod 追加仕様書（v1.3.2）

`SPEC_v1.3.1.md`（Mod 1.3.1）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/spec/SPEC_v1.3.2.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.3.1 がリリース済み。1.3.1 の内容を土台にする
- 内容: 他のプレイヤーのヒット音を、採掘だけでなく、**機械の加速と成長**のヒットでも鳴らす
- この仕様書の内容は、Mod のバージョン **1.3.2** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.3.1 → **1.3.2**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.3,1.4)`）は、変えない。1.3.x 同士は、互いに接続できる
- **パッチなので、互換性を破る変更を入れない**。今ある `OtherHitMessage`（ブロックの位置と連続ヒット数）を、そのまま使う。クライアントは、成長・機械のヒット通知にも連続ヒット数を入れて送っているので、ヒット通知も変えない

## 1. 問題

他のプレイヤーが採掘の弱点に当てたときはヒット音が聞こえるが、機械の加速（と成長）のときは聞こえない（ユーザーの報告）。サーバーが、受け付けた採掘のヒットだけを、近くのプレイヤーに転送していたため。

## 2. 変更

- サーバーが受け付けた**成長・機械**のヒットも、採掘と同じく、そのブロックから 16 ブロック以内の他のプレイヤーに転送する（`OtherHitMessage`）
- 聞こえ方は採掘と同じ（ブロックの位置から、離れるほど小さく。楽器・音量は各自の `othersHitSound` / `othersHitVolume`。音階は叩いたプレイヤーの連続ヒット数）
- 1.3.x の古いクライアント（1.3.0・1.3.1）も、同じパケットなので、そのまま鳴る（叩いた側のサーバーが 1.3.2 なら）
- 動物・釣り・弓・近接のヒットは、今までどおり転送しない

## 3. README に書くこと

- 「ヒット音」の節の、他のプレイヤーのヒット音の説明を「採掘・成長・機械のヒット音」に直す
- 「最新版」の行を 1.3.2 にし、「更新履歴」に 1.3.2 を追加する（通信内容は変わっていない。サーバーを 1.3.2 にすると聞こえる）
- README の「開発」の節の仕様書へのリンクと、`CLAUDE.md` の「仕様の正本」の一覧に、`doc/spec/SPEC_v1.3.2.md` を足す

## 4. ユーザーに確認してもらうこと

- 専用サーバー（または LAN）で、他のプレイヤーが機械・作物の弱点に当てると、そのブロックの位置からヒット音が聞こえること。音階が上がっていくこと
- 採掘のヒット音は、今までどおりであること
