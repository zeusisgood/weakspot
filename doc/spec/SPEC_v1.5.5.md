# 弱点破壊 Mod 追加仕様書（v1.5.5）

`SPEC_v1.5.4.md`（Mod 1.5.4）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/spec/SPEC_v1.5.5.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.5.4 がリリース済み。1.5.4 の内容を土台にする
- 内容: 近接の弱点が見える距離を **16 → 32 ブロック**にする（ユーザーの指示。もっと遠くの敵から弱点の位置を確かめられるように）
- この仕様書の内容は、Mod のバージョン **1.5.5** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.5.4 → **1.5.5**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.5,1.6)`）は、変えない
- **パッチなので、互換性を破る変更を入れない**。見える距離はクライアントだけが使う定数（`MeleeSight.SIGHT_DISTANCE`）なので、通信・設定・保存データは変わらない。古いサーバーにつないでも同じように動く

## 1. 見える距離

- `client/MeleeSight.SIGHT_DISTANCE` を 16 → **32**（ブロック）
- 探し方（バニラの照準と同じ選び方、ブロックに遮られたら出さない）と、**当てられるのは攻撃が届く距離だけ**なのは変えない
- 弱点の大きさは変えない（遠いほど画面の上では小さく見える）

## 2. README

- 近接の弱点の節の「16 ブロック以内」を「32 ブロック以内」に
- 「最新版」の行を 1.5.5 にし、「更新履歴」に 1.5.5 を追加する（クライアントだけの変更。通信内容は変わっていない）
- 「開発」の節の仕様書へのリンクに `doc/spec/SPEC_v1.5.5.md` を足す
- ガイドの本は、距離の数を書いていないので変えない

## 3. `CLAUDE.md` に書くこと

- 「仕様の正本」の一覧に `doc/spec/SPEC_v1.5.5.md` を足す。現行のバージョンを 1.5.5 に
- 近接の弱点の説明の「視線の先 16 ブロック以内」を「32 ブロック以内（1.5.5）」に

## 4. ユーザーに確認してもらうこと

- 30 ブロックくらい先の敵に照準を合わせると、弱点が出ること
- 遠くの敵の弱点が小さすぎて見えにくくないか
- 重くならないこと（照準の先を毎フレーム 32 ブロック探す）
