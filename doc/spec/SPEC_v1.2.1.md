## 0. バージョンとパッチの制約

- バージョンは 1.2.0 → **1.2.1**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.2,1.3)`）は、変えない。1.2.x 同士は、互いに接続できる
- **パッチなので、互換性を破る変更を入れない**（パケット・`SyncedSettings`・保存データ・既存の設定キーは変えない）
- **クライアントだけ**の変更。`[クライアント]` の設定を1つ足す

## 1. 問題

動物の弱点は、当たり判定の箱の面に描いている。ニワトリは箱（幅 0.4）より模型のほうが外に出ている（羽、頭とくちばし、しっぽ）ので、弱点の面が模型の内側に入り、深度テストで体に隠れる。

## 2. 変更: 隠れた部分を薄く透かして描く

- **自分の動物の弱点**は、これまでどおり（深度テストあり）に描いたうえで、**深度テストを切って、薄く**もう一度描く
  - 薄く描く分の濃さは、通常の濃さ × **0.35**。色・形・移動の演出（残像）は通常と同じ
  - 体に隠れていない部分は、2回分が重なって少し明るくなるが、よいものとする
  - ヒットの瞬間に広がるリングも、動物の弱点のものは同じように薄く透かして描く
- 当たり判定・弱点の位置は変えない（見た目だけの変更）
- ブロックの弱点（採掘・成長・機械）は変えない
- **他のプレイヤーのマークは変えない**（壁越しに見えてしまうため）

## 3. 設定

| キー | 初期値 | 説明 |
|---|---|---|
| `animalSpotSeeThrough` | true | `[クライアント]` 自分の動物の弱点が体に隠れたとき、隠れた部分を薄く透かして表示するか |

- 設定画面の説明（`weakspot.general.animalspotseethrough.tooltip`）を `en_us.lang` と `ja_jp.lang` に足す
- README の設定表（クライアント）に足す
