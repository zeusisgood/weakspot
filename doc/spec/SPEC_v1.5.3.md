# 弱点破壊 Mod 追加仕様書（v1.5.3）

`SPEC_v1.5.2.md`（Mod 1.5.2）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/spec/SPEC_v1.5.3.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.5.2 がリリース済み。1.5.2 の内容を土台にする
- 内容: 機械の加速が 1 ヒット目から効いていることを分かりやすくする（「機械 ×n」がコンボ 25 から出るので、それまで加速していないと勘違いする、というユーザーの指摘）。①HUD の言葉を「コンボボーナス ×n」に。②README とガイドの本の書き方を直す。③加速中の機械に、速さに合わせた色の粒子を出す。実際の速さを HUD に出すのは、通信が変わるので 1.6.0（`SPEC_v1.6.md`、下書き）で行う
- この仕様書の内容は、Mod のバージョン **1.5.3** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.5.2 → **1.5.3**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.5,1.6)`）は、変えない
- **パッチなので、互換性を破る変更を入れない**。パケット・`SyncedSettings`・保存データは変えない。粒子はバニラの粒子の仕組み（`WorldServer#spawnParticle`）で送る。設定は、サーバーだけが使うもの（送らない）を1つ足す

## 1. HUD の言葉

- 「機械 ×n」（`weakspot.combo.machine`）を「**コンボボーナス ×n**」（英語は「**Combo bonus ×n**」）にする。出す条件と数は変えない（コンボの掛け数。×1.0 のときは出さない）
- ディスペンサー・ドロッパーの「発射 ×n」は変えない

## 2. 加速中の機械の粒子（サーバー）

- 機械の加速が続いている間（`MachineBoost` が有効な間。最後のヒットから `machineBoostDurationTicks`）、その機械のまわりに、**色つきの粉の粒子**（`EnumParticleTypes.REDSTONE`。数を 0 にして、色を渡す）を出す。レッドストーンの部品・ディスペンサーも同じ
- **色**は、その機械の今の倍率を `machineBoostMultiplier` で割った値（＝コンボの掛け数。上限の設定で抑えられていれば、その分小さい）で決める

| 掛け数 | 速さ（初期値） | コンボ（初期値） | 色 |
|---|---|---|---|
| 〜1.25 未満 | 4倍速 | 1〜24 | 水色 `#55FFFF` |
| 1.25〜 | 5倍速 | 25〜 | 黄 `#FFFF55` |
| 1.5〜 | 6倍速 | 50〜 | 橙 `#FFAA00` |
| 2〜 | 8倍速 | 100〜 | 赤 `#FF5555` |
| 2.5〜 | 10倍速 | 250〜 | ピンク `#FF55FF` |
| 3〜 | 12倍速 | 500〜 | 紫 `#AA55FF` |
| 4〜 | 16倍速 | 1000〜 | 金 `#FFD700` |

  - バニラの粉の粒子は、渡した色を少し暗くばらつかせて描くので、実際の色は少し暗めになる
- **量**は、速いほど多く: 1 tick に **倍率 ÷ 8** 個（端数は持ち越す）。4倍速で 2 tick に 1 個、8倍速で 1 tick に 1 個、16倍速で 1 tick に 2 個
- **場所**は、ブロックの当たり判定の箱の、底面以外の面のランダムな位置から、少し（0.05）外側
- **見せる相手**は、近くのプレイヤー全員（バニラの粒子と同じ範囲）
- 出す場所のチャンクが読み込まれていないときは、出さない
- 色と量の計算は `common/MachineParticles` に置き、単体テストを書く（量の端数の持ち越しは `MachineBoost` に持つ）
- 設定 `machineBoostParticles`（初期値 true。**サーバーだけが使う**。送らない）で止められる

## 3. README とガイドの本

- README の「機械の加速」の節を、「当てると、すぐにその機械が **4 倍速**で動く（初期値）。コンボが続くと、さらに速くなる（最大 16 倍速）」の順に書き直す。HUD の「コンボボーナス ×n」は、4 倍速に**上乗せ**される分であることを書く。粒子の色の表を載せる
- 設定表（サーバー）に `machineBoostParticles` を足す
- ガイドの本の 5 ページ目（機械の加速）を、「当てるとすぐに速くなる（まわりに色の粒が出る）。コンボが続くと、さらに速くなる」ことが分かる書き方にする（日本語で 150 文字くらいまで）
- 「最新版」の行を 1.5.3 にし、「更新履歴」に 1.5.3 を追加する（通信内容は変わっていない）
- 「開発」の節の仕様書へのリンクに `doc/spec/SPEC_v1.5.3.md` を足す

## 4. `CLAUDE.md` に書くこと

- 「仕様の正本」の一覧に `doc/spec/SPEC_v1.5.3.md` を足す。現行のバージョンを 1.5.3 に
- コンボの表示の説明の「機械 ×n」を「コンボボーナス ×n」に。`MachineAccelerator` の説明に粒子を足す
- `SPEC_v1.6.md`（下書き）の「機械 ×n」を「コンボボーナス ×n」に読み替える（1.6.0 で「機械 n倍速」に変える）

## 5. ユーザーに確認してもらうこと

- かまどを叩くと、1 ヒット目から水色の粒が出ること。コンボ 25 で黄、50 で橙…と色が変わり、速いほど粒が多いこと
- 叩くのをやめると、すぐに粒が止まること
- ほかのプレイヤーにも粒が見えること
- コンボの下の表示が「コンボボーナス ×1.25」になっていること
- 粒子が多すぎて邪魔・重くないこと
