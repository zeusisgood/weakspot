# 弱点破壊 Mod 追加仕様書（v1.3.3）

`SPEC_v1.3.2.md`（Mod 1.3.2）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/spec/SPEC_v1.3.3.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.3.2 がリリース済み。1.3.2 の内容を土台にする
- 内容: 他のプレイヤーのヒット音を、**動物・釣り・弓・近接**のヒットでも鳴らす（これで、すべての種類で鳴る）
- この仕様書の内容は、Mod のバージョン **1.3.3** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.3.2 → **1.3.3**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.3,1.4)`）は、変えない。1.3.x 同士は、互いに接続できる
- **パッチなので、互換性を破る変更を入れない**。1.3.2 と同じく、今ある `OtherHitMessage`（位置と連続ヒット数）をそのまま使う。クライアントは、どの種類のヒット通知にも連続ヒット数を入れて送っているので、ヒット通知も変えない

## 1. 変更

サーバーが受け付けた次のヒットも、採掘・成長・機械と同じく、鳴らす位置から 16 ブロック以内の他のプレイヤーに転送する。

| 種類 | 鳴らす位置 |
|---|---|
| 動物 | 当てた動物の位置 |
| 釣り | 浮きの位置 |
| 弓 | 弓を引いているプレイヤーの位置 |
| 近接 | 殴った敵の位置（ヒットを受け付けたとき。クリティカルになったかは問わない） |

- 位置はブロックの中心に丸める（`OtherHitMessage` がブロックの位置を運ぶため。最大 0.5 ブロックずれる）
- 聞こえ方は今までと同じ（楽器・音量は各自の `othersHitSound` / `othersHitVolume`、音階は叩いたプレイヤーの連続ヒット数）
- 弱点のマークの表示（弓・釣り・近接は他のプレイヤーに見せない）は、変えない
- ユーザーの判断で、4 つとも入れる（弓は引いている人の位置で鳴るので、PvP では居場所が分かりやすくなる。近接は、バニラのクリティカルの音と重なる）
