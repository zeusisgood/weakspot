# 弱点破壊 Mod 追加仕様書（v1.6.3）

`SPEC_v1.6.2.md`（Mod 1.6.2）に対する**パッチ**の仕様。ここに書かれていないことは、それと現行実装のままとする。
仕様書は、リポジトリの `doc/` ディレクトリに置く（この仕様書は `doc/spec/SPEC_v1.6.3.md`）。
仕様と食い違う実装をする場合は、`CLAUDE.md` のリリースの流れ（止まる条件）に従う。

- 対象: Minecraft Java Edition 1.12.2 / Forge 14.23.5.2860
- 前提: 1.6.2 がリリース済み。1.6.2 の内容を土台にする
- 内容: 頭の上のコンボ数（1.6.0）を、しゃがんでいる人にも出す（不具合の修正）
- この仕様書の内容は、Mod のバージョン **1.6.3** として、リリースする

---

## 0. バージョンとパッチの制約

- バージョンは 1.6.2 → **1.6.3**（`build.gradle` の `version` と `WeakSpotMod.VERSION` の2か所を、そろえて変える）
- `WeakSpotMod.ACCEPTED_VERSIONS`（`[1.6,1.7)`）は、変えない
- **パッチなので、互換性を破る変更を入れない**。クライアントの描き方だけの変更。通信・設定・保存データは変わらない

## 1. 不具合と直し方

- 1.6.0 の仕様（`SPEC_v1.6.md` §5）で「しゃがんでいる人の分は出さない（名前と同じ）」としていた。ところが、機械の弱点はしゃがんで右クリックしないと出せないので、**機械を叩いている人のコンボが、頭の上に一度も出なかった**（しゃがんで叩く動物も同じ）。サーバーは数を送っていて、描く側の条件だけが原因（ユーザーの報告）
- `client/OtherCombos` の「しゃがんでいる人は出さない」をやめ、**しゃがんでいても出す**（ユーザーの判断）
  - 壁の向こうは、今までどおり見えない（深度テストあり）。透明になっている人の分は、今までどおり出さない

## 2. README

- 頭の上のコンボ数の説明の「しゃがんでいる人の分は出ません」を消す
- 「最新版」の行を 1.6.3 にし、「更新履歴」に 1.6.3 を追加する（クライアントだけの修正。通信内容は変わっていない）
- 「開発」の節の仕様書へのリンクに `doc/spec/SPEC_v1.6.3.md` を足す

## 3. `CLAUDE.md` に書くこと

- 「仕様の正本」の一覧に `doc/spec/SPEC_v1.6.3.md` を足す。現行のバージョンを 1.6.3 に
- 頭の上のコンボの説明の「しゃがみ中は出さない」を「しゃがみ中も出す（1.6.3。機械はしゃがんで叩くため）」に

## 4. ユーザーに確認してもらうこと

- ほかの人がしゃがんで機械を叩いてコンボが 10 を超えると、その人の頭の上に「n HIT」が出ること
