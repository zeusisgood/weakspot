この仕様書は `doc/spec/SPEC_v1.11.2.md`。

- 前提: 1.11.1 がリリース済み
- この仕様書の内容は、Mod のバージョン **1.11.2** として、リリースする

## 0. バージョンと互換性

- バージョンは 1.11.1 → **1.11.2**（`build.gradle` の `version` と `WeakSpotMod.VERSION`）
- 通信内容は変わらない。設定の項目は足さない（オン・オフの設定は作らない。ユーザーの判断）。`configVersion` は上げない
- サーバーとクライアントの両方が要る機能なので、クライアント側は `ServerFeatures.since("1.11.2")` で囲む。サーバー側は、1.11.2 より古いクライアントには自動の対象を使わない（§3）

## 1. やりたいこと（ユーザーの判断）

- 成長の弱点の対象を、追加リスト（`growthExtraBlocks`）に書かなくても、**ランダム tick を受け取るブロック（`Block#getTickRandomly()`）なら自動で拾う**（相談: 追加リストのホワイトリストをやめて似た仕組みのものに自動対応。IC2 の建築用フォームが固まるのを早めたい、から）
- 考え方は Random Things の「Time in a Bottle」と同じ（1.12.2 版のソースで確認: ブロックの種類を問わず、ブラックリストもなく、`getTickRandomly()` なら `randomTick` を呼ぶ）。放っておけば起きることを早めるだけ
- **案 A3**: 自動で拾ったブロックは、**しゃがんで右クリックを押しっぱなし**にしたときだけ弱点を出す（通常の右クリックを横取りしない。機械の弱点と同じ操作）
- 除外は今の `growthExcludedBlocks` だけで行う。**初期値は増やさない**（草ブロック・草・背の高い草花のまま。葉・耕地・氷なども対象になる）
- しゃがんだときに機械とも自動の対象とも取れるブロックは、**機械を優先**（今の判定の順のまま）

## 2. 対象の判定（`RightClickTargets`）

- 自動の対象（仮に `isAutoGrowable`）: 次をすべて満たすブロック
  - `getTickRandomly()` が true
  - `growthExcludedBlocks` にない
  - 追加リストにない（追加リストにあるブロックは、書いた条件だけで決める。条件を満たさないときに自動で拾い直さない）
  - `IGrowable` でない（`IGrowable` は今どおり `canGrow` で決める。育ちきった作物を自動で拾い直さない）
- `classify` の順: 機械（しゃがんで両手が空）→ 成長（今の判定）→ 収穫 → **自動の成長（しゃがんでいて、メインハンドが空 = `HeldItems.isFree`）**。種類は `HitKind.GROWTH`（統計・コンボ・設定・種類のオン・オフは成長と共通）
- しゃがむのは弱点を**出すとき**の条件。出たあとの「まだ対象か」の確認（クライアントの弱点の取り消し、サーバーの `grow` のくり返し）は、しゃがみを見ずに `isGrowable` か `isAutoGrowable` で見る（押しっぱなしの途中でしゃがみをやめても消えない。消したほうがよければ実装のときに相談）
- 固まって別のブロックになり、それがランダム tick を受け取らなければ（IC2 のフォーム → 壁 の想定）、そこで弱点は消える。受け取り続けるブロックは、押しっぱなしの間ずっと出る（「育ちきった」を判定しない）

## 3. 古い版との組み合わせ

- 1.11.2 のクライアント + 古いサーバー: `ServerFeatures.since("1.11.2")` が false なら、クライアントは自動の対象を使わない（右クリックも止めない）
- 古いクライアント + 1.11.2 のサーバー: サーバーは `PlayerText.clientVersion(player)` が 1.11.2 未満（または不明）なら自動の対象を使わない（クライアントが止めていない右クリックを、サーバーだけで止めない）

## 4. 効果と知らせ

- 効果は今の成長と同じ（1 ヒットで `growthTicksPerHit` 回 `randomTick`。弱点の面も同じ: 1 マス全体なら照準の面、それ以外は一番大きい面）
- 自動の対象には「育たない」の知らせ（`GrowthWarnings` の暗い・`growthStuckHits`）を出さない（変わらないことがあるブロックも多いため）
- 成長バーは今どおり `age` / `stage` を持つときだけ

## 5. 設定の説明

- `growthExcludedBlocks` のコメントと日英の `.tooltip` に「しゃがんで右クリックで自動で拾うブロック（ランダム tick を受け取るもの）にも効く」を足す
- `growthExtraBlocks` のコメントと `.tooltip` に「書かなくても、ランダム tick を受け取るブロックは、しゃがんで右クリックすれば対象になる。書くと、しゃがまなくても出る・状態の条件を付けられる」を足す（「葉・草ブロック…は書かない」の注意は残す）

## 6. README・doc・ガイドの本・お知らせ

- `doc/play.md` の「作物・苗木の成長」に、しゃがんで右クリック長押しでランダム tick を受け取るブロック全般（Mod のブロックも。例: IC2 の建築用フォーム）に弱点が出ること・機械が優先・知らせは出ないこと・困るブロックは `growthExcludedBlocks` に書くこと。追加リストの「注意」は、自動の対象にも当てはまる（葉・耕地・氷なども早まる）と書き直す

## 8. ユーザーに確認してもらうこと

- IC2 の建築用フォームに、しゃがんで素手で右クリック長押しで弱点が出て、当てると早く固まる。固まると消える
- しゃがまなければ出ない（フォームなど、追加リストにないブロック）。作物・サトウキビ・ゴムの木は今どおりしゃがまなくても出る
- しゃがんで機械に右クリックしたときは、今どおり機械の弱点
- 葉・耕地などにも出る（初期値で除外しない判断のまま困らないか）
