## 1. 照準のまわりの弱点の位置の決め方を見直す

### 1.1 不具合

- 上下だけに出る弱点（はしご・走りなど）は、次の位置を「今の照準から 10〜20 度、上か下（ランダム）」で決めている。上の弱点に当てると照準が上を向き、次もまた上に出ることが続くと、少しずつずれて**真上・真下まで行ってしまう**（ユーザーの報告）
- 左右だけ（近接）と全方向の弱点も、同じように照準がずれていく（近接では、敵から顔がそれていく）

### 1.2 新しい決め方（ユーザーの判断: 交互と高さの帯の組み合わせ）

照準からの距離（10〜20 度。`BowMath.offsetRange`）は今のまま。次の弱点を照準の**どちら側**に出すかを、次のように決める。

- **上下の向き**（MC の pitch。水平が 0、下が正）:
  - 照準が水平から **±20 度以内**なら、**前の弱点と反対側**に出す（上 → 下 → 上）。最初の 1 つはランダム
  - 照準が水平より 20 度より上を向いていたら、**下**（水平に戻る側）に出す
  - 照準が水平より 20 度より下を向いていたら、**上**に出す
  - この決まりで、照準は水平から約 40 度以内を行き来し、真上・真下には行かない
- **左右の向き**: いつも**前の弱点と反対側**に出す（左 → 右 → 左）。最初の 1 つはランダム
- **全方向の弱点**: 上下の成分の向きは上の「上下の向き」、左右の成分の向きは「左右の向き」で決める。10〜20 度の輪の上で、その向きの 4 分の 1 の範囲（斜めを含む）のどこかに出す
- 前の位置から最低限離す決まり（今の `MIN_MOVE_DEGREES`）は、今のまま守る（取れなければ一番離れた位置）

### 1.3 どの弱点に使うか

| 出し方 | 弱点 | 決め方 |
|---|---|---|
| 上下だけ | はしご・走り、馬・豚に乗っているときの乗り物・弓・食事・投げる物 | 上下の向き（交互＋水平から ±20 度） |
| 左右だけ | 近接 | 左右の向き（交互） |
| 全方向 | 弓・食事・投げる物・ゲート・トロッコ／ボートの乗り物 | 上下の向き＋左右の向き |
| 全方向（エリトラ） | エリトラ | 上下も左右も**交互だけ**（水平に戻す決まりは使わない。急降下・急上昇のときに照準を水平へ引き戻すと、飛び方に影響するため。ユーザーの判断） |

- ブロックや動物の面に出る弱点（採掘・成長・機械・動物・収穫）、釣り（水面）、画面のマーカー（睡眠・エンチャント）は変えない

### 1.4 実装

- 向きの決め方は `common/BowMath` に置き、単体テストを書く（交互になること、±20 度を越えたら水平の側になること、エリトラの交互だけの決め方、前の位置から離れること）
  - `HudSpot` は、前の弱点の側（上か下、左か右）を覚える。弓（`BowSpot`）も同じ決め方にする
- 定数: 水平の帯の角度 `HORIZON_BAND_DEGREES = 20`

## 2. README・ガイドの本

- README の弓・乗り物・はしご・走り・近接などの節の「照準から少し離れたどこか」の説明に、「交互に出て、照準が水平から離れすぎないようにする」ことを 1 か所（照準のまわりの弱点の共通の説明）にまとめて書く
- ガイドの本は変えない（遊び方の説明は同じ）
- 「最新版」の行と「更新履歴」（クライアントだけの変更。1.8.x 同士は接続できる）、「開発」の節の仕様書へのリンク

## 3. `CLAUDE.md` に書くこと

- 仕様の一覧に足す。現行を 1.8.1 に
- `HudSpot` の説明に、上下・左右の向きの決め方（交互、水平から ±20 度を越えたら水平の側、エリトラは交互だけ）を足す

## 4. ユーザーに確認してもらうこと

- はしご・走りで弱点に当て続けても、照準が真上・真下まで行かないこと（上と下に交互に出ること）
- 近接の弱点が左右に交互に出て、敵から顔がそれていかないこと
- 弓・食事・投げる物・ゲートの弱点が、照準のまわりに偏らずに出ること
- エリトラで急降下・急上昇しているときに、弱点に当てても照準が水平に引き戻されないこと
